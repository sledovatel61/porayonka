## Текущее состояние (после раунда 18)

Живая приёмка Windows показала критичные регрессии и новые задачи:

1. **Колонка «Действия» занимает много места**, при этом редактирование всё равно открывается кликом по строке. Кнопки в колонке дублируют функционал карточки. Скрины: `Текущее состояние.png`.
2. **Ресайз колонок неудобен**: цепляясь курсором за разделитель, можно двигать только влево; за левый край — только вправо. Должно работать как в Excel (перетаскивание разделителя в обе стороны). Нужно, чтобы ручная ширина колонок сохранялась в `controls_settings.json` и восстанавливалась после перезапуска.
3. **В карточке контроля не хватает быстрых действий**: нет кнопки «Контроль исполнен» и «Исполнен пункт». Скрин: `Текущая карточка контроля.png`.
4. **Скролл в карточке контроля при выборе исполнителей/контролёров** пролистывает страницами, ползунка нет. Скрин: `карточка контроля исполнители добавить ползунок скролла как в справочнике.png`. Также список «За кем контроль» должен показывать только контролёров из справочника, а не всех людей. Скрин: `Карточка контроля за кем контроль.png`.
5. **Фильтры не работают** — при использовании в логе ошибки, карточки перестали открываться после добавления нового контроля. Лог: `ЛОГ.txt`. Скрин: `Текущее состояние.png`.

## Задачи раунда 19

### 1. Убрать колонку «Действия» из таблицы

- В `ui/controls/controls_tab.py` удалить колонку `actions` из `_W`, `TABLE_HEADERS`, `_header_cell` и `_build_row`.
- Удалить кнопки редактирования/удаления/продления/исполнения из строки таблицы.
- Оставить открытие карточки контроля по клику на строке (как сейчас).
- Освободившееся место отдать соседним колонкам (особенно «Содержание», «Исполнители», «За кем контроль»). Пересчитать `_FIXED` и `_fit_widths()`.
- Сохранить hover и курсор `CLICK` на строке.

### 2. Исправить ресайз колонок и сохранение ширины

- Разделитель между колонками должен позволять перетаскивать **в обе стороны** (влево и вправо) за всю ширину разделителя, как в Excel.
- Проверить логику `_on_header_drag` / `_on_header_drag_end`: дельта должна корректно применяться к обеим колонкам, суммарная ширина таблицы не должна «плясать».
- **Сохранение ширин**: `_save_col_widths()` уже пишет в `controls_settings.json`, но нужно убедиться, что:
  - при старте вкладки ширины восстанавливаются из `settings["col_widths"]` без сброса;
  - если сумма сохранённых ширин не влезает в окно — их можно пропорционально ужать, но не терять пользовательские настройки;
  - изменения ширины применяются сразу при отпускании разделителя.
- Добавить smoke-тест: изменить ширину колонки → сохранить → пересоздать вкладку → ширина восстановлена.

### 3. Быстрые кнопки в карточке контроля

В футере карточки контроля (`detail_card`), слева от кнопки «Удалить»:

#### 3.1. «Контроль исполнен»

- Зелёная/синяя кнопка (подобрать цвет из палитры Glass).
- По нажатию открывается `AlertDialog` (через `page.open()`):
  - Заголовок: «Подтверждение исполнения контроля».
  - Поле для ввода/выбора даты фактического исполнения (русский календарь).
  - Кнопки «Отмена» / «Исполнен».
- При подтверждении:
  - `control.done = True`;
  - `control.done_date` = выбранная дата;
  - контроль уходит в архив (как при ручном исполнении);
  - показывать toast «Контроль исполнен»;
  - закрыть карточку и обновить таблицу.
- В сводке карточки отображать: «Исполнен: <дата>».

#### 3.2. «Исполнен пункт»

- Жёлтая кнопка рядом с «Контроль исполнен».
- По нажатию открывается `AlertDialog`:
  - Список пунктов задания (`ControlTask`) с checkbox + название + ответственные + дата исполнения (русский календарь).
  - Админ выбирает пункт, ставит дату, нажимает «Отметить исполненным».
- При подтверждении:
  - `task.is_done = True`;
  - `task.done_date` = выбранная дата;
  - обновить сводку карточки: например, «п. 2 исполнен — Гайнутдинов С.И., 11.08.2026»;
  - обновить плашку пункта/точки в карточке.
- Если все пункты исполнены — предложить закрыть весь контроль (не обязательно, можно просто обновить UI).

### 4. Скролл и фильтрация списков в карточке контроля

- **Исполнители в карточке**: inline-мультивыбор должен использовать тот же паттерн, что и справочники:
  - `Column(scroll=ft.ScrollMode.ALWAYS)` + локальная `ScrollbarTheme` (как в раунде 17);
  - шаг колеса остаётся ограничен Flet 0.23.2, но ползунок должен быть видимым и draggable.
- **«За кем контроль»**: dropdown/мультивыбор должен показывать только тех, кто отмечен ролью `controller` в `person_roles` (см. раунд 18). Если никто не отмечен — fallback на дефолтных контролёров (`Потемкин С.А.`, `Чашин Э.А.`).
- **Пункты задания — ответственные**: там тоже использовать список с ролями (исполнители) и видимым скроллом.

### 5. Исправить фильтры и открытие карточек

- **Критично**: после добавления нового контроля карточки перестали открываться. Найти причину в `_build_row` / `_open_detail` / `_filtered` / `_persist`.
  - Возможные причины: пустой/битый `control_id`, `None` в данных, конфликт имён, пересоздание таблицы без обновления обработчиков on_click, `_filtered` возвращает не тот список.
  - Проверить лог `ЛОГ.txt` и воспроизвести.
- **Фильтры не работают**: при выборе значения в dropdown падает ошибка (см. `ЛОГ.txt`).
  - Проверить обработчики `_on_*_change`, `_apply_filters`, `_filtered`.
  - Возможно, `executor_filter_dd`/`controller_filter_dd` теперь используют канонические списки из `person_roles`, но обработчики ожидают старые значения.
  - Исправить без нарушения логики фильтрации по ролям.
- После исправления: smoke-тест должен покрывать создание контроля, открытие карточки, применение фильтров, очистку фильтров.

## Технические ограничения

- **Flet строго 0.23.2.** Не повышать.
- Цвета 8-hex — только `#AARRGGBB` (не CSS `#RRGGBBAA`). Динамические полупрозрачные через `with_alpha(color, '22')` → `#22RRGGBB`.
- `print()` — только ASCII (без русских букв, emoji, спецсимволов); UI-текст — русский.
- `ft.icons.*` вместо emoji.
- Внутри `Column(scroll=AUTO/ALWAYS)` — без `expand=True` (кроме горизонтальных спейсеров в `Row`), без `wrap=True`, без `animate*`, без `gradient`/`shadow` на мелких контейнерах.
- Все `.update()` контролов — через `_safe_update()`; в горячих обработчиках (hover) — `_quiet_update` без `traceback.print_exc()`.
- Вложенные `AlertDialog` — только подтверждения; карточка контроля остаётся `Container`-overlay в `Stack`.
- Рамки с `border_radius` — равномерная толщина всех сторон.
- Не ломать: Excel-импорт/экспорт (раунд 18), сетевую синхронизацию, архив, роли людей, другие вкладки.
