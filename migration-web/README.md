# Порайонка: переезд «Контролей» в браузер

Дата плана: 16.09.2026. Статус: **план подготовлен, реализация не начата**.

## Решение простыми словами

Делаем новую версию раздела «Контроли». Программа работает на одном постоянно доступном компьютере в локальной сети. Сотрудники открывают её в браузере. Интернет для повседневной работы не нужен.

На Windows 7 не устанавливаем Python, Flet, сервер и специальные DLL. Там нужен только проверенный браузер. Однако Win7 и старые браузеры остаются риском безопасности; переезд не делает их поддерживаемыми современными системами.

Существующие контроли, пункты, сроки, вложения и Excel переносим. Старую программу не ломаем. Зональных криминалистов и отделы пока оставляем в ней. Справочник людей, нужный контролям, переносим отдельно.

**Главное изменение:** вместо нескольких копий общего файла будет одна серверная база. Сохранили контроль — сервер подтвердил сохранение, остальные пользователи получают обновление. Нет незаметного объединения разных копий по часам компьютеров.

## Как работаем

1. Оркестратор составляет задания, принимает решения вместе с владельцем и проверяет результаты.
2. Агенты AI Arena пишут код в отдельных ветках GitHub.
3. Оркестратор проверяет изменения и тесты, затем внедряет принятый этап.
4. Владелец проверяет удобство и работу на настоящем Win7.

Сначала доказываем, что выбранное решение быстро работает на старом компьютере. Только затем переносим весь функционал. Не обещаем заранее число дней или отсутствие ошибок. Десять этапов ниже — крупные проверяемые результаты, а не обещание десяти сообщений без исправлений.

## Что пока не утверждено

Наличие подходящего сервера, его ОС, конкретный браузер Win7, количество пользователей и объём базы пока неизвестны. Технологическое предложение — FastAPI + React + PostgreSQL; окончательное закрепление версий и инфраструктуры происходит в W00–W01. PostgreSQL — новая предлагаемая зависимость, а не уже используемая в проекте база.

Отказ от офлайн-редактирования и ограничения уведомлений при закрытом браузере должны быть отдельно приняты владельцем **до разработки основной системы**.

## Уточнение предыдущего вывода

Основания для переезда: сложный интерфейс Flet, локальный web-сервер на Win7, файловая синхронизация и накопленные обходные решения. Но замеров на реальном Win7 в этом обследовании не было. Нельзя утверждать, что все тормоза вызваны только Flet, а все сорок раундов были исправлением ошибок: среди них были новые функции и изменения дизайна. Новая архитектура уменьшает эти риски, но её скорость необходимо измерить.

Этот пакет содержит только документацию. Код, зависимости, рабочие данные и сборки старой программы не изменялись при его создании.
