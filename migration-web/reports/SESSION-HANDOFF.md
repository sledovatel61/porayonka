## 4. Ключевые решения и статус вопросов

**Принято планом и подтверждено обследованием:** стек Python/FastAPI + React/TypeScript + PostgreSQL,
HTTPS на одном адресе, статика локально без CDN, без офлайн-редактирования, серверная авторизация,
`revision`/409 вместо слияния «кто позже», лёгкий опрос изменений, двухфазная загрузка файлов.

**Предложения агента (требуют утверждения):** явный `build.target` под Chrome 109 / Firefox 115 ESR;
отказ от Tailwind v4 и от `vite-plugin-singlefile`; прототип `src/` не является основой (он про вкладку отделов);
единый серверный предикат видимости вместо четырёх legacy-реализаций; стабильные id промежуточных точек;
сопоставление колонок Excel по заголовку; детерминированные UUIDv5 при миграции; `legacy_raw` для каждой записи;
интерфейс — один вариант «графит» (таблица + карточка справа).

**Блокирующие вопросы владельцу:** В-01 сервер и ответственный, В-02 ОС сервера, В-03 PostgreSQL,
В-04 точный браузер на Win7. **Существенные:** В-05 автоперенос периода, В-06 разрешение/RAM,

В-14 архив, В-15 окно переключения и откат. Полный текст — `decisions.md` §4.

**Расхождения плана и кода, требующие решения:** D-01 (дата поступления), D-02 (`end_date` у разового),

## 7. Особенности среды, которые нужно учитывать при продолжении

- **История git может сбрасываться.** Песочница пересоздаёт checkout между ходами: `git reflog` показал только
  `clone` и `checkout`, прежние коммиты агента исчезли, хотя файлы рабочего каталога сохранились. Перед любым
  продолжением проверять `git log --oneline -3` и `git status --porcelain`; если документы снова окажутся
  незакоммиченными — закоммитить их повторно (содержимое не менять) и выполнить обычный push без force.
- **Подключение GitHub.** `gh auth status` может быть как недействительным, так и восстановленным; при ошибке
  авторизации не подменять её обещанием публикации, а сообщать ограничение и просить переподключить GitHub в Arena.
- **Архивная копия документов.** На случай повторного сброса истории семь документов дополнительно переданы
  владельцу одним ZIP-архивом через интерфейс Arena (вне репозитория, в git не добавляется).
