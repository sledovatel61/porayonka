## 1. КРИТИЧНЫЙ РЕГРЕСС: карточка контроля не открывается

Симптом: клик по строке/карандашу → экран затемняется (dim виден), сама карточка НЕ появляется, **в консоли пусто**.
Причина почти наверняка: исключение в `_open_detail`/`_build_detail` проглатывается `try/except: pass` (поэтому «в логах пусто»), или после правки «высота по контенту» карточка получила нулевую высоту/уехала за пределы.
Сделать:
1. Найди все `except: pass` / `except Exception: pass` на пути открытия карточки и замени на `except Exception: traceback.print_exc()` (traceback — ASCII-safe). Это обязательное правило на будущее: **в UI-обработчиках исключения не глушим молча**.
2. Почини падение/схлопывание: карточка должна появляться с высотой по контенту, max `min(780, 0.9*окна)`, по центру.
3. Проверь: открытие по клику на строку, по карандашу, «Добавить контроль» (новая карточка), закрытие, сохранение.

### 2.2 Фильтр «Все исполнители»: теперь фильтрует в ПУСТО
После твоего `_norm`-фикса выбор исполнителя даёт пустой список — значит, строки не совпадают НИКОГДА.
Причина: options фильтра построены из справочника (`load_criminalists()` — полные ФИО), а в `ctl.executors` реальных данных могут лежать другие строки (короткие «Семисенко И.Ю.», лишние пробелы и т.п.). `any(_norm(f) == _norm(ex))` → всегда False → пусто.
Сделать:
- **Options фильтра строить из РЕАЛЬНЫХ данных**: `sorted({e for c in controls for e in c.executors})` (distinct из текущего списка), отображение через `short_name()`. Тогда выбранное значение гарантированно совпадает с данными.
- Сравнение оставить с `_norm` (страховка), но ключ — точное значение из данных.
- Отладка: временно `print(repr(f_executor), repr(ctl.executors))` (ASCII) при фильтрации, убедись в совпадении, потом print убери.

### 2.3 Фильтр «Все контролёры»: только те, кто реально есть

## 3. Напоминание ограничений

- `#AARRGGBB` (альфа первая); динамика `f"#22{color[1:]}"` / `with_alpha`.
- `Column(scroll=AUTO)`: без `expand` (кроме спейсеров в Row), `wrap`, `animate`, `shadow`, `gradient`; рамки равномерной толщины.
- Исключения в UI-обработчиках — `traceback.print_exc()`, не `pass`.
- Не ломать: данные, Excel, сеть, архив, роли, вкладки 1–2, контракты; без вложенных диалогов; `ft.icons.*`; ASCII `print()`; русский UI.
