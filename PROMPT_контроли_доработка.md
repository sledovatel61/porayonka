## 1. Доработка таблицы (controls_tab.py)

### 1.1 Цвет и «слипшиеся» строки
Сейчас таблица выглядит слишком синей, строки слипаются в одно полотно — не видно границ между ними. На мокапе фон холоднее (серо-синий графит), строки читаются раздельно.

Сделай:
- Фон вкладки и полотна таблицы — темнее и нейтральнее: `#080d1c` / `#0a1120`, полотно `#b3141e30`-диапазона (подбери, сверяясь с мокапом: оно темнее и менее «синее», чем сейчас).
- Разделители строк заметнее: `#26ffffff` (было `#1affffff` — еле видно).
- Чередование строк чуть контрастнее: alt `#4d16213d` или лёгкий `#0dffffff` — чтобы глаз цеплялся за строку.
- Строка height 54–56, вертикальный ритм воздушный, как на мокапе.

### 1.2 Колонка «Действия» — вернуть заметные кнопки
Сейчас справа только тусклая галка — пользователь не видит, где редактировать и удалять. В продакшн-версии кнопки видны, на мокапе — колонка «Действия» с карандашом и корзиной.

Сделай:
- Хедер: подпись «Действия» (UPPERCASE, как остальные).
- Кнопки 28–30 px, ghost-стиль: `bgcolor` transparent, hover `#12ffffff`, `border_radius` 8, `icon_size` 18, контрастные цвета иконок:
  - **Редактировать** — `EDIT_OUTLINED`, цвет `#4f8cff` (открывает карточку, как клик по строке);
  - **Исполнено** — `CHECK_CIRCLE_OUTLINE`, `#2fd08b`;
  - **Продлить срок** — `UPDATE_OUTLINED`, `#ffd166`;
  - **В архив** — `DELETE_OUTLINE`, `#ff5c6e`.
- В режиме «Архив»: «Восстановить» + «Удалить навсегда» тем же стилем.
- Ширину колонки увеличь до ~120 px (4 иконки с воздухом), ужми «Содержание».

### 1.3 Hover без задержки
Сейчас подсветка строки при движении мыши срабатывает с огромной задержкой: `row.update()` на таблице из 134 строк тормозит.

Сделай:
- Убери тяжёлую работу из обработчика hover: никаких пересчётов, try/except с широким захватом оставь, но внутри — только смена `bgcolor` + `update()`.
- Если лаг сохраняется — подсветку делать через лёгкий внутренний контейнер-«вуаль» (один уровень, без обновления всей строки с 15 детьми), либо, в крайнем случае, убери hover-заливку совсем и оставь только `MouseCursor.CLICK` + подсветку по левой полосе. Приоритет — отзывчивость.

## 2. ПОЛНЫЙ редизайн карточки контроля (detail_overlay)

Текущая карточка: всё в одну скомканную колонку, лейблы наляписто, календарь обрезан, пункты задания громоздкие. Переработай с нуля по мокапу — просторно, сгруппировано, удобно. Функционал и обработчики сохранить (сохранение, инлайн-мультивыборы, периодика, пункты, milestones, вложения, удаление).

### 2.1 Каркас
- Панель: ширина ~920, высота ~min(780, 0.9 окна), radius 16, стекло `#cc141f33`-подобное (темнее текущего, см. п.1.1), кромка сверху `#2effffff`, dim `#cc04070f`.
- Внутри: заголовок фиксированный сверху, футер с кнопками фиксированный снизу, середина — `Column(scroll=AUTO)` (правила скролла — те же: без `expand`/`wrap`/`animate`/`shadow`).
- Заголовок: иконка + «Карточка контроля» size 17 bold, справа — вх. № крупно (когда редактирование) и X закрытия.

### 2.2 Компоновка — ДВЕ колонки (ключевое отличие от текущей)
Левая колонка (~55%, spacing 14):
1. **Секция «Реквизиты»**: Вх. № + Дата поступления в одну строку (2 поля); Инициатор — dropdown + компактная кнопка «+» для нового (поле «Новый инициатор» появляется инлайн по клику, не жрёт место постоянно); Содержание — textarea min 3 строки.
2. **Секция «Исполнение»**: Исполнители — инлайн-мультивыбор (header «Исполнители · Выбрано: N»); «За кем контроль» + Тип + Периодичность — в одну строку (три dropdown, каждый с label сверху).
3. **Секция «Комментарий»** — одна строка.

Правая колонка (~45%, spacing 14):
1. **Секция «Сроки»** — стеклянная подпанель: поле «Следующая дата исполнения» + **календарь, раскрытый сразу** (как на мокапе: «Август 2026», Пн–Вс, сетка 7×6 видна целиком, клик = мгновенный выбор). Под ним «Следующие: …» (для периодики) мелким `#93a3c7`, «Конечная дата».
2. **Секция «Пункты задания»** — заголовок + кнопка «+ Добавить пункт»; список пунктов — компактные блоки (см. 2.3).
3. **Секция «Скан задания»** — кнопка «Прикрепить файл» (ghost), список файлов мелко.

На узких окнах (<1100 px) колонки складываются в одну (проверь при ресайзе).

### 2.3 Пункт задания — компактный блок
Сейчас: огромный toggle, обрезанный календарь, наляписто. Сделай один аккуратный блок (стекло, radius 10, padding 10):
- Строка 1: drag-иконка (опционально) + название пункта (TextField, grow) + удалить (иконка 16, `#ff5c6e`).
- Строка 2: «Ответственные» — инлайн-мультивыбор (тот же компонент, компактный).
- Строка 3: «Срок» — date field + переключатель «исполнено» НОРМАЛЬНОГО размера (не гигантский toggle: `ft.Switch` scale ~0.8 или чекбокс с подписью) + дата исполнения мелко, если исполнен.
- Комментарий пункта — однострочный, hint «Комментарий…».

### 2.4 Футер
Слева: «Удалить» (danger ghost — текст/рамка `#ff5c6e`, только при редактировании). Справа: «Отмена» (ghost) + «Сохранить» (accent `#4f8cff`, height 40, radius 10, иконка SAVE).

### 2.5 КРИТИЧНО: календарь не должен обрезаться
Сейчас панель календаря (280 px) рендерится внутри узкого контейнера поля/пункта и клиппится родителем — видно 3 дня недели, кнопки «Сегодня/Очистить» уезжают. Скрин прилагается в истории чата: календарь шириной ~150 px с обрезанными колонками.

Решение (выбери надёжное):
- Выпадающая панель календаря должна добавляться в **верхний слой detail_overlay** (`ft.Stack` карточки), позиционируясь `top`/`left` рядом с полем (вычисляй примерно по индексу секции, или открывай по центру правой колонки) — НЕ внутри скролл-колонки и не внутри контейнера поля.
- Минимальная ширина панели 280 px всегда; родитель не должен иметь `clip` на этом пути.
- В секции «Сроки» (правая колонка) календарь показывай развёрнутым постоянно — там ему место.
- Для полей в пунктах задания и фильтрах «С/По» — выпадашка поверх, как описано выше.
- Проверь: календарь из пункта задания виден целиком (7 колонок + «Сегодня»/«Очистить»), не налезает на переключатель «исполнено».

## 3. Ограничения (прежние, напоминаю)

- Flet 0.23.2, без новых зависимостей; `ft.icons.*`; UI-текст на русском; `print()` — ASCII.
- Цвета с прозрачностью — только `#AARRGGBB` (альфа ПЕРВАЯ). Конкатенация: `f"#22{color[1:]}"`, не `f"{color}22"`.
- Внутри `Column(scroll=AUTO)`: без `expand=True` (кроме спейсеров в Row), без `wrap=True`, без `animate*`/`shadow`/`gradient` на мелких контейнерах, `border_radius` — только с равномерной толщиной сторон.
- Не ломать: логику данных, экспорт/импорт Excel, сеть, архив, роли, вкладки 1–2, контракты функций. Вложенные `AlertDialog` запрещены — только инлайн-панели; диалоги подтверждений — `page.open()/page.close()`.
