## Цель

Довести UI вкладки «Контроли» до финального состояния по 5 пунктам:

1. Hover строк таблицы — мгновенный, без задержек.
2. Колонка «Действия» — иконки прижаты к правому краю ячейки (ровно так же, как левая статусная полоса прижата к левому краю).
3. Модалка «Справочники» — содержимое отцентрировано/распределено по ширине, плюс редактирование существующих записей.
4. Карточка контроля — уголки не обрезаны (скругление сохраняется по всему периметру).
5. Предпросмотр вложения — увеличить размер, чтобы документ/фото было удобно читать.

## Задача 1 — Hover без задержки

**Проблема:** сейчас подсветка строки появляется с заметной задержкой.

**Что нужно:**
- Hover должен реагировать мгновенно при движении курсора по строкам.
- Решение должно работать в реальном GUI Windows + Flet 0.23.2.
- Если невозможно добиться идеальной скорости текущим подходом (`row.on_hover` + `row.update()`), допустимо:
  - убрать hover-заливку фона полностью и оставить только смену курсора (`mouse_cursor=CLICK`);
  - или сделать hover только по акцентной левой полосе (она уже есть);
  - или любое другое минимальное решение, главное — отсутствие лага.
- В любом случае строка должна оставаться кликабельной и визуально читаемой.

**Куда смотреть:** `porayonka-app/ui/controls/controls_tab.py`, функции `_build_row`, `_make_hover` (если есть), `on_hover` у строки.

## Задача 2 — Колонка «Действия»: иконки к правому краю

**Проблема:** иконки действий (редактировать, исполнено, продлить, в архив) сейчас расположены не у самого правого края ячейки, а с отступом/смещением.

**Что нужно:**
- Иконки в колонке «Действия» должны быть прижаты к правому краю ячейки (alignment end).
- Левый край строки имеет акцентную полосу статуса, упирающуюся в левую границу. По аналогии правая группа иконок должна упираться в правую границу ячейки.
- Сохранить текущие 4 иконки и их порядок.
- Не увеличивать ширину колонки «Действия» без необходимости; текущей ширины достаточно.

**Куда смотреть:** `porayonka-app/ui/controls/controls_tab.py`, `_build_row`, блок `actions_col`/`actions_row`.

## Задача 3 — Модалка «Справочники»: центрирование и редактирование

**Проблема:**
- Содержимое модалки прижато к левому краю (см. `Справочники.png`).
- Нельзя редактировать существующие записи — только добавлять новые и удалять.

**Что нужно:**
- Растянуть содержимое модалки по ширине панели: поля ввода и списки должны занимать всю доступную ширину, а не прилипать к левому краю.
- Добавить редактирование существующих значений:
  - вариант A: двойной клик по строке → поле ввода с текущим значением;
  - вариант B: иконка карандаша рядом с крестиком удаления → открывается редактирование;
  - выбери удобный вариант, но он должен работать без вложенных диалогов.
- Сохранить добавление/удаление и кнопку «Применить».
- После «Применить» фильтры должны перестраиваться с новыми значениями.

**Куда смотреть:** `porayonka-app/ui/controls/controls_tab.py`, функция `_open_references` и вспомогательные `_build_ref_list`/`_apply_refs`.

## Задача 4 — Карточка контроля: не обрезать уголки

**Проблема:** на скрине `Карточка контроля.png` видно, что углы карточки обрезаны (нижние углы выглядят прямоугольно, а не скруглёнными).

**Что нужно:**
- Все четыре угла карточки должны быть скруглены одинаково (`border_radius` должен применяться).
- Исправить через `clip_behavior=ft.ClipBehavior.HARD_EDGE` и/или убедиться, что дочерние элементы не выходят за границы Container.
- Если причина в `Stack` + `detail_overlay` — добавить промежуточный `Container` с `clip_behavior`.
- Скругление должно сохраняться при любом размере карточки (включая после resize).

**Куда смотреть:** `porayonka-app/ui/controls/controls_tab.py`, `detail_overlay`, `detail_card`, `drag_surface` и т.д.

## Задача 5 — Предпросмотр вложения: увеличить размер

**Проблема:** предпросмотр вложения слишком маленький (см. `Предпросмотр надо побольше.png`), документ/скриншот неудобно читать.

**Что нужно:**
- Увеличить окно предпросмотра минимум до **80–90% ширины и высоты окна приложения**.
- Для изображений: `ImageFit.CONTAIN` с масштабированием под доступное пространство.
- Для PDF: увеличить иконку/превью и оставить кнопку «Открыть в программе».
- Шапка предпросмотра (название файла + кнопки «Открыть», «Удалить», «Закрыть») должна оставаться видна, не перекрывать изображение.
- Предпросмотр не должен обрезаться окном карточки (лежит в общем overlay, это уже так — сохранить).

**Куда смотреть:** `porayonka-app/ui/controls/controls_tab.py`, `_preview_attachment`, `preview_root`, `preview_body`.

## Технические ограничения (обязательны)

- Flet 0.23.2 — не повышать.
- Внутри `Column(scroll=ft.ScrollMode.AUTO)` — никаких `expand=True` (кроме горизонтальных спейсеров в `Row`), `wrap=True`, `animate*`, `shadow`, `gradient` на мелких контейнерах.
- Цвета с прозрачностью — только формат `#AARRGGBB`, не `#RRGGBBAA`. Динамические — через `with_alpha` из `glass_theme.py`.
- `print()` в консоль — только ASCII (без русских букв, emoji, спецсимволов), чтобы избежать `UnicodeEncodeError` на Windows cp1251.
- UI-текст (`text=...`) — на русском.
- `ft.icons.*` вместо emoji.
- Все `.update()` контролов в файле уже через `_safe_update()` — сохранить так; в горячих обработчиках hover — `_safe_update` без `traceback.print_exc()`.
- Не ломать логику данных, сохранение, сеть, Excel-экспорт/импорт, архив, вкладки «Следственные отделы» и «Зональные».
- Вложенные `AlertDialog` запрещены — использовать инлайн-панели/оверлеи.
