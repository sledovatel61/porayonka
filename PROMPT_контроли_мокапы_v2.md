# Промпт: мокапы v2 — ВИЗУАЛЬНЫЕ СТИЛИ вкладки «Контроли» (5+ скинов)

> **Задача:** создать серию мокапов, различающихся **ВИЗУАЛЬНЫМ СТИЛЕМ**
> (палитра, контраст, типографика, поверхности), а не раскладкой. Минимум
> 5 скинов. В последнем сообщении напиши ТОЧНОЕ имя ветки с результатом.

---

## 1. Контекст

- **Репозиторий:** `https://github.com/sledovatel61/porayonka.git`, ветка `main`.
- В `design/mockups/` уже лежит ПЕРВАЯ серия мокапов (01–05): раскладки
  (Excel-Pro таблица, Master-Detail, карточки, доска, дашборд). Изучи её.
- **Вывод пользователя по первой серии:** идеи раскладок хорошие и будут
  использованы, НО визуальный стиль у всех одинаковый — текущая палитра
  приложения (тёмно-синяя). Нужна **вариация ВНЕШНЕГО ВИДА**: другие палитры,
  контрастность, характер.
- **Твоя задача — стили, а не раскладки.** Чтобы сравнение было честным,
  раскладку используем ОДНУ — «Excel-Pro» (таблица с фильтрами в шапке по
  колонкам, чипы-счётчики, тулбар сверху, карточка-оверлей) — см.
  `design/mockups/01_excel_pro.html` за образец структуры. Переменная — СКИН.
- Мокапы кладутся в **`design/mockups/v2/`**. Код приложения не трогать.
- Реализация потом — в Flet 0.23.2 (десктоп, Windows). Поэтому в каждом
  скине используй ТОЛЬКО воспроизводимое в Flet: сплошные цвета, границы,
  радиусы, отступы, типографику. **Без** backdrop-blur, теней-мешков,
  градиентов на мелких элементах (допустим градиент на крупной статичной
  шапке — отметь это в мокапе комментарием).

## 2. Скины (минимум 5, разнохарактерные)

1. **«Midnight Gold»** — глубокий тёмно-синий фон (#0a1220…) + золото/янтарь
   как акцент (кнопки, активные элементы), солидный «гос» вид, чёткие
   границы, спокойная роскошь.
2. **«Emerald Ops»** — фон с зеленоватым подтоном (#0c1a16…) + изумрудный
   акцент (#10b981…), «оперативный пульт», свежесть, хорошая читаемость.
3. **«Graphite HC» (high contrast)** — почти чёрный фон, белый текст,
   яркие статусные цвета, сильные границы, нулевая «мыльность» —
   максимальная читаемость для уставших глаз.
4. **«Modern SaaS» (Linear/Notion style)** — нейтральные zinc/slate,
   один фиолетово-индиго акцент (#6366f1…), мягкие границы, воздух,
   аккуратная типографика, «светлая» тёмная тема.
5. **«Amber Terminal»** — дата-денс, IDE-стиль: моноширинные цифры/даты
   (JetBrains Mono/Consolas для чисел), янтарный акцент, компактная
   таблица, «рабочий инструмент».
6. *(опционально)* свой шестой скин, если есть идея сильнее.

**Важно:** в каждом скине статусная система (просрочено/сегодня/скоро/
в работе/исполнено/завершён) должна оставаться различимой — адаптируй
оттенки статусов под скин, но сохрани семантику (красный/жёлтый/оранж/
зелёный/серый/синий).

## 3. Контент каждого мокапа (одинаковый у всех)

Чтобы сравнивались СТИЛИ, контент и структура — общие:

- Шапка вкладки: «Контроли», индикатор «Локально», кнопки «Добавить
  контроль», «Импорт Excel», «Экспорт Excel», настройки.
- Чипы-счётчики: Все 134 · Просрочено 2 · Сегодня 2 · Скоро 5 ·
  В работе 114 · Исполнено 9; переключатель «Активные | Архив».
- Таблица с фильтрами в шапке по колонкам (вторая строка шапки — фильтр
  каждой колонки: поиск по вх. №, dropdown'ы инициатор/исполнители/за кем/
  тип/статус, даты с/по). Колонки: №, вх. № (ПОЛНОСТЬЮ, не обрезан),
  дата пост., инициатор, содержание (2 строки), исполнители, за кем, тип,
  срок исполн., статус (цветная пилюля), действия.
- 6–7 строк данных — те же, что в первой серии (см.
  `design/mockups/01_excel_pro.html`).
- **Второе состояние: карточка контроля** (оверлей): секции, поля по два
  в ряд, инлайн-выбор исполнителей, пункты задания, скан задания,
  липкий футер с кнопками.
- **Русский календарь**: «Август 2026», Пн–Вс, выбранный день акцентом,
  один клик.
- **Палитра скина**: в углу каждого мокапа — компактный блок-свотч
  (основные цвета скина с hex) — нужен для последующей реализации.

## 4. Технические требования

- `design/mockups/v2/01_midnight_gold.html`, `02_emerald_ops.html`,
  `03_graphite_hc.html`, `04_modern_saas.html`, `05_amber_terminal.html`
  (+ шестой, если делаешь).
- Полностью автономные (CSS в `<style>`, без CDN/внешних шрифтов;
  системный стек шрифтов; моношрифт — `Consolas, "Courier New", monospace`).
- Раскладка под 1600×900, не ломается на 1280×800. Русский UI.
- В каждом файле переключение «список ⇄ карточка» (как в первой серии).
- `design/mockups/v2/index.html` — обзорная: превью скинов, названия,
  2–3 слова характера каждого, ссылка «открыть».
- Обновить `design/mockups/README.md`: добавить раздел «Серия v2 (скины)»
  с описанием каждого и своей рекомендацией.

## 5. Критерии качества

- Скины **действительно разные** по характеру (не перекрашенные клоны:
  разные фон/подтон, акцент, границы, типографика, плотность).
- Каждый скин доведён до ума: статусы различимы, текст читаем (контраст
  текста к фону ≥ нормального для тёмных тем), таблица и карточка
  проработаны одинаково тщательно.
- Всё воспроизводимо в Flet сплошными цветами/границами/радиусами.
