## 1. Контекст

  там задокументированы все layout-ловушки Flet 0.23.2.

**Состояние:** вкладка «Контроли» функционально ЗАВЕРШЕНА и работает

периодика, milestones, schema v2). Менять логику, data-слой и функционал

вкладку визуально сильной, при этом ничего не сломать.

## 2. Что не так сейчас (прямая речь пользователя + скрины)

1. **«Всё неброско, всё сливается»** — нет визуальной иерархии: фон, строки,
   панели и кнопки почти одного тона; статусы не играют роль якорей.
2. **«Текст трудно воспринимается, особенно фильтры наверху»** — мелкие кегли,
   низкий контраст вторичного текста.
3. **«Заголовки входящих номеров обрезаются»** — колонка «вх. №» узкая:
   «Иссоп-216-1017-26/дсп» виден как «Иссоп-216-101…».
4. **«Фильтры в куче друг на друге»** — фильтры свалены двумя рядами сверху.
   Пользователь хочет **фильтры непосредственно над/в своих колонках**
   (модель — как в Excel: у каждой колонки свой фильтр в шапке).
5. **«Всё мелко»** — кегли 11–12, строки 58 px, тесные отступы.
6. **Календарь на английском** («Select date», Cancel/OK) и требует кнопки OK.
   Нужен **русский календарь с выбором даты в один клик** (клик по дню —
   дата выбрана, окно закрылось).
7. **Карточка контроля (detail overlay) — «ещё та боль»**: поля свалены
   вертикальной лентой, Switch «исполнено» гигантский, секции не отделены,
   действия внизу не закреплены.

## 3. Требования к редизайну

### 3.1 Визуальная иерархия и контраст

- Чёткая трёхуровневая глубина: фон страницы < панели/строки < приподнятые
  элементы (шапка таблицы, карточка, пилюли). Подобрать оттенки в рамках
  тёмной палитры `core/constants.py` (можно аккуратно добавить 1–2 оттенка
  в COLORS, например `surface_raised`, и использовать их).
- Статус — главный визуальный якорь строки: цветная полоса слева заметнее
  (5–6 px), пилюля статуса — точка + текст, читаемая с расстояния.
- Hover-строка (смена bgcolor), чёткие border'ы, единый ритм отступов
  (4/8/12/16), единые радиусы (8/10/12).
- Типографика: базовый кегль **13**, вторичный 11–12, заголовки колонок
  11 bold uppercase (letter_spacing ~0.5 через `ft.TextStyle(letter_spacing=)`),
  ключевые значения (вх. №, дата срока) — semibold. Кегль 10 и меньше — только
  для мелких подписей-подсказок.
- Кнопки в шапке — иерархия: primary «Добавить контроль», secondary
  импорт/экспорт, ghost настройки/архив.

### 3.2 Фильтры — Excel-модель (по колонкам)

- **Убрать два ряда фильтров сверху.** Вместо этого — **вторая строка шапки
  таблицы с фильтрами по колонкам** (под заголовком каждой колонки — свой
  контрол): «вх. №» — текстовый поиск; «Инициатор», «Исполнители», «За кем»,
  «Тип», «Статус» — dropdown «Все …»; «Дата пост.» и «Срок исполн.» —
  выбор дат (с/по). Фильтры шириной ровно в свою колонку (те же `_W`).
- Сверху остаётся одна компактная панель: глобальный поиск + чипы-счётчики
  статусов + «Активные | Архив» + кнопки.
- Кнопка «Сброс» фильтров — одна, заметная, рядом с шапкой или в ней.
- Логика фильтрации (`_filtered`) не меняется — меняется только раскладка
  контролов.

### 3.3 Таблица

- «вх. №»: ширина под «Иссоп-216-1017-26/дсп» (~170–190 px) либо перенос на
  2 строки — номер должен читаться ПОЛНОСТЬЮ без tooltip'а.
- Строки 62–66 px, воздух между строками, содержание до 2 строк с нормальным
  кеглем (12–13).
- Шапка (заголовки + строка фильтров) визуально отделена и **липкая**
  (не уезжает при скролле списка: список — отдельный scroll-контейнер
  под ней, при этом соблюдать правила layout из AGENTS.md).
- Действия строки (исполнить/продлить/архив) — иконки с tooltip'ами,
  видимые всегда или по hover (на выбор, но единообразно).

### 3.4 Русский календарь с выбором в один клик

- Все точки выбора даты (фильтры, карточка, пункты, milestones) используют
  **русскоязычный календарь**: русские месяцы и дни недели, кнопки
  «Отмена»/без «OK» — **клик по дню сразу выбирает дату и закрывает**.
- Вариант A: проверить, локализуется ли `ft.DatePicker` в Flet 0.23.2
  (`page.locale = ft.Locale("ru")` и нужны ли delegates) и можно ли
  подтверждать выбор без OK. Если да — использовать его.
- Вариант B (предпочтительнее при сомнениях): **свой компактный календарь** —
  всплывающая панель (Container в overlay/Stack): шапка «‹ Август 2026 ›»,
  сетка дней 7×N, дни другого месяца приглушены, сегодня подсвечено,
  выбранная дата акцентом, клик по дню = выбор + закрытие. Компонент
  переиспользуемый (`ui/controls/ru_date_picker.py`), без вложенных модалок
  (помни про баг вложенных диалогов — рендерить внутри текущего overlay).
- Поле даты: read_only + кликабельное, с иконкой календаря и крестиком
  очистки.

### 3.5 Карточка контроля — нормальная форма

- Секции с заголовками и разделителями: **Основное** (вх. №, дата поступления,
  инициатор, содержание), **Исполнение** (исполнители, за кем, тип,
  периодичность, сроки + подсказка циклов), **Пункты задания**,
  **Промежуточные точки**, **Скан задания**.
- Короткие поля — **по два в ряд** (вх. № + дата; инициатор + за кем;
  тип + периодичность; срок + конечная дата), не лентой в одну колонку.
- Switch «исполнено» в пунктах — компактный (scale ~0.8) или заменить на
  чекбокс/чип «Исполнено»; сейчас он рендерится огромным.
- Инлайн-выбор исполнителей: свёрнут — одна строка «Выбрано: N (фамилии)»;
  развёрнут — панель с поиском + чекбоксами **ограниченной высоты** со
  скроллом, не распирающая форму.
- **Липкий футер** карточки: «Удалить» слева, «Отмена»/«Сохранить» справа,
  всегда виден при скролле формы. Закрытие по Esc/клику по затемнению —
  с подтверждением, если есть несохранённые изменения (dirty-флаг).
- Ширина карточки ~860–900, высота ~0.82 окна, внутренний скролл только у
  области контента.

### 3.6 Архив и прочее

- Режим «Активные | Архив» — сегмент-переключатель в верхней панели,
  визуально отличный от кнопок.
- В архиве — причина и дата архивации читаемо; действия «Восстановить» /
  «Удалить навсегда» — с тем же визуальным качеством.

## 4. Жёсткие ограничения

- Flet строго 0.23.2. Никаких новых зависимостей.
- **Не менять**: `core/` (модели, data, exporter), контракты функций,
  формат `controls.json` (schema v2), функционал (фильтрация, сортировка,
  архив, вложения, импорт/экспорт, сеть, уведомления, milestones, роли).
- Layout-правила из `AGENTS.md`: внутри `Column(scroll=AUTO)` без
  `expand=True`/`wrap=True`/`animate`/`gradient`/`shadow` на мелких
  контейнерах; фиксированные размеры там, где требуется; `ft.icons.*`;
  `print()` только ASCII; UI-текст на русском.
- Не сломать вкладки «Следственные отделы» и «Зональные».
- Обновить `AGENTS.md` (раздел 32): что изменено визуально, новые компоненты
  (например, ru_date_picker), новые ключи COLORS.

## 5. Проверка перед сдачей

1. `python -c "import sys; sys.path.insert(0, 'porayonka-app'); import main"` — OK.
2. Headless smoke (page-заглушка): вкладка собирается; шапка содержит строку
   фильтров; у колонок фильтры своей ширины; карточка открывается/закрывается;
   фильтрация/сортировка работают; архив переключается; нет `scroll+tight+expand`.
3. Календарь: выбор дня одним кликом возвращает дату; месяцы/дни недели на
   русском; очистка даты работает.
4. **Ручная приёмка GUI Windows** (обязательна, чек-лист):
   - контраст и читаемость на 1280×800 и 1920×1080;
   - вх. № читается полностью;
   - фильтры стоят над своими колонками и фильтруют;
   - календарь русский, дата выбирается одним кликом без OK;
   - карточка: секции, два-в-ряд, компактный switch, липкий футер,
     закрытие с подтверждением при изменениях;
   - функционал без регрессий: добавить/изменить/архив/восстановить,
     импорт/экспорт Excel, вложения.
