## Контекст

- Репозиторий: `https://github.com/sledovatel61/porayonka.git` (ветка `main`).
- Приложение: `porayonka-app/main.py`.
- Стек: Python 3.10+, Flet **строго 0.23.2**, openpyxl 3.1.5.
- Окружение: Windows, запуск `python porayonka-app/main.py`.
- Данные приложения хранятся в `%APPDATA%\porayonka\`.

> Перед началом прочитай `AGENTS.md` в корне репозитория — там описана архитектура, история layout-проблем, текущее состояние и следующие задачи (разделы 15–18 и 20).

## Текущая проблема / Цель

Пользователь хочет привести вкладку «Зональные криминалисты» к современному топовому UI с анимациями, сохранив весь рабочий функционал и **не сломав работающие плашки**.

## Требования к редизайну

### 1. Общий внешний вид и анимации

- Современный, аккуратный, «топовый» интерфейс: плавные анимации (hover-эффекты на плашках, переключение активности, прогресс-бары), мягкие тени, скругления, цвета из текущей тёмной палитры `core/constants.py`.
- Плашки должны красиво распределяться на экране, сохраняя компактность: ~96 px высотой, 280 px шириной, 4 плашки в ряд.
- Все иконки — через `ft.icons.*`, никаких emoji в UI Flet.
- UI-текст на русском.

### 2. Новая разворачиваемая секция «Сводка по криминалистам»

- Добавить сворачиваемую/разворачиваемую панель (по аналогии с текущей «Настройкой сбора данных» и «Общей сводкой»).
- В развёрнутом виде показать **список активных криминалистов**, участвующих в сборе.
- Для каждого криминалиста должно быть видно, **кто сколько и каких показателей сдал**, а не только общий процент. Например:
  - ФИО криминалиста.
  - По каждому пункту шаблона: иконка/галочка «сдано» или «не сдано», либо числовое значение.
  - Можно использовать мини-индикаторы, прогресс-бар по пунктам, сводную таблицу или аккордеон — главное, чтобы детализация была наглядной.
- В свёрнутом виде — компактная однострочная сводка (как сейчас: активных, сдано, общий прогресс).

### 3. Убрать поиск по ФИО

- Поле «Поиск по ФИО...» в тулбаре зональной вкладки лишнее, так как все криминалисты помещаются на экране.
- Удалить поисковое поле и связанную с ним логику (`search_ref`, `_set_search`, `visible_count_text` при необходимости).
- Фильтры «Все / Не заполнившие / Неактивные» **оставить**.

### 4. Кнопка «Очистить все данные»

- Добавить кнопку для мгновенного сброса всех заполненных `submissions` (всех данных форм криминалистов) без потери:
  - текущего шаблона (`template`);
  - списка криминалистов (`criminalists`);
  - их активности (`is_active`).
- По нажатию показать диалог подтверждения: «Очистить все введённые данные? Структура формы и список криминалистов сохранятся».
- После сброса обновить все плашки и сводки.
- Для сброса можно использовать `clear_zonal_submissions()` из `core/zonal_data.py` и `collection.submissions.clear()`.

### 5. Сохранить весь текущий функционал

- Добавление / редактирование / удаление криминалиста.
- Переключение активности (`is_active`) на плашке.
- Фильтры плашек (кроме удаляемого поиска): «Все», «Не заполнившие», «Неактивные».
- Сохранение / загрузка / очистка шаблонов.
- Экспорт в Excel.
- Кнопка «Копировать не сдавших».
- Клик по плашке открывает модальное окно заполнения формы (`create_form_input_modal`).

## Технические ограничения (строго соблюдать)

- **Flet 0.23.2** — не повышать версию.
- **Не ломать работающие плашки.** См. `AGENTS.md` раздел 15.12 — текущий layout плашек подтверждённо работает. Любое изменение плашки (`criminalist_tile.py`) или их сетки (`zonal_tab.py`) должно сохранять компактность и видимость содержимого.
- Не добавлять `expand=True` внутрь `Column`/`Container` с `scroll=ft.ScrollMode.AUTO` — это источник схлопывания layout.
- Все иконки — через `ft.icons.*`, никаких emoji в UI Flet.
- `print()` в консоль — только ASCII (без русских букв, emoji и спецсимволов), чтобы избежать `UnicodeEncodeError` на Windows с кодировкой `cp1251`.
- UI-текст (`text=...`) может и должен быть на русском.
- Не добавлять новые зависимости без согласования.
- Не трогать логику данных, модели, сохранение, экспорт, вкладку «Следственные отделы».
