## Контекст

«Порайонка» — десктопное приложение на Flet 0.23.2, вкладка «Контроли» для учёта контролей/распоряжений. В раундах 20–28 реализованы: Glass Dark UI, сетевая синхронизация через shared JSON + polling, admin/user-редакции, трей/автозапуск, web-версия для Win7, импорт/экспорт Excel, вложения, пароль admin в настройках.

### 1. Предпросмотр PDF-вложений

### 3. Пароль администратора в настройках

**Нужно:**

### 6. Блокировка одновременного редактирования контроля двумя админами

**Сейчас:** если два админа открыли одну и ту же карточку и сохраняют, последний перезаписывает изменения первого.

**Нужно:**
- При открытии карточки контроля создавать lock-файл в shared-папке:
  - `\\192.168.0.60\общая\Гайнутдинов\Porayonka workspace\.locks\<control_id>.lock`
  - Содержимое: JSON `{"user": "ФИО админа", "machine": "...", "since": "ISO"}`
- При закрытии/сохранении карточки — удалять lock.
- При попытке открыть контроль, у которого есть активный lock, показывать AlertDialog:
  - «Контроль вх.№ … уже редактируется администратором <ФИО> с <время>»
  - Кнопки: «Обновить и открыть» (перечитать shared, проверить lock заново) / «Отмена».
- Lock считается «мёртвым», если старше N минут (например, 10) — позволять открыть.
- В фоновом polling'е проверять свои lock'и (если админ забыл закрыть карточку и приложение упало, lock остаётся — через 10 минут другие смогут открыть).
- Не блокировать просмотр/чтение, только редактирование.

### 8. Защита edition.json от удаления

**Сейчас:** если пользователь удалит `edition.json` рядом с exe, приложение запустится в admin-режиме (default).

**Нужно:**
- Сделать fallback-копию `edition.json.bak` рядом с `edition.json`.
- При запуске, если `edition.json` отсутствует, но `edition.json.bak` есть — восстановить из бэкапа.
- Если и то, и другое отсутствует, но есть `%APPDATA%\porayonka\edition.json` — использовать его (приоритет appdata над default admin).
- `load_edition` должен читать (в порядке приоритета):
  1. env `PORAYONKA_EDITION`
  2. `edition.json` рядом с exe
  3. `edition.json.bak` рядом с exe
  4. `%APPDATA%\porayonka\edition.json`
  5. default admin
- При установке/сборке `edition.json` и `edition.json.bak` копируются рядом с exe.

### 9. Оффлайн-вложения с авто-выгрузкой в shared

**Сейчас:** вложения копируются в shared, но если shared недоступен — файл остаётся локально; при возврате shared он не выгружается автоматически, и чужие вложения не подтягиваются.

**Нужно:**
- Если при прикреплении файла shared недоступен — сохранять локально в `%APPDATA%\porayonka\controls_attachments\<control_id>\`.
- В фоновом polling'е (раз в ~60 сек) проверять: есть ли локальные вложения, отсутствующие в shared; если shared доступен — копировать их в `controls_attachments` в shared-папке.
- При чтении shared (merge/poll) проверять: есть ли в shared вложения, отсутствующие локально; если да — копировать к себе.
- В UI незаметно для пользователя: файлы из локального и shared-хранилища отображаются единым списком.
- Если файл есть и локально, и в shared — не дублировать.

## Технические ограничения

- Flet строго 0.23.2. Не повышать.
- Внутри `Column(scroll=AUTO)` — без `expand=True` (кроме горизонтальных спейсеров в Row), без `wrap=True`, без `animate*`, без `gradient`/`shadow` на мелких контейнерах.
- Цвета 8-digit — только `#AARRGGBB`; динамические полупрозрачные через `with_alpha(color, '22')` → `#22RRGGBB`.
- `print()` — только ASCII (без русских букв, emoji, спецсимволов).
- UI-текст (`text=...`) — на русском.
- `ft.icons.*` вместо emoji.
- Все `.update()` контролов через `_safe_update()` (исключение — горячие hover, там `_safe_update` молча).
- Не ломать раунды 20–28: Excel round-trip, справочники, сеть, архив, вложения, ресайз, карточка, фильтры, read-only user, трей/автозапуск, web Win7.
