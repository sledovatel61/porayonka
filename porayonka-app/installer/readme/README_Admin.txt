Порайонка v2.0 DARK final — Администраторская версия
=====================================================

Установка:
1. Запустите Порайонка_Админ_Setup.exe.
2. Выберите папку установки (по умолчанию C:\Program Files\Порайонка_Админ).
3. При желании установите пароль для входа в программу.
4. Поставьте галочки: ярлык на рабочем столе, автозапуск, запуск после установки.

Возможности:
- Вкладки «Следственные отделы», «Зональные криминалисты», «Контроли».
- Импорт и экспорт контролей в Excel.
- Редактирование карточек контроля, пунктов задания, вложений.
- Сетевая синхронизация через общую папку.
- Управление справочником людей и инициаторов.

Данные хранятся в папке:
%APPDATA%\porayonka\

При переустановке данные сохраняются.
