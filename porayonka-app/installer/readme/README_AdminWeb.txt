Порайонка v2.0 DARK final — Администраторская WEB-версия для Windows 7
======================================================================

Установка:
1. Запустите Порайонка_Админ_Web_Setup.exe.
2. Выберите папку установки (по умолчанию C:\Program Files\Порайонка_Админ_Web).
3. Поставьте галочки: ярлык на рабочем столе, автозапуск, запуск после установки.

Как работает:
- При запуске поднимается локальный web-сервер и открывается браузер.
- Не закрывайте фоновое окно сервера, пока работаете с программой.
- Программа висит в системном трее; щелчок по значку снова открывает браузер.
- Сервер: http://127.0.0.1:8555

Возможности (ПОЛНАЯ редакция, как у нативного Админа):
- Вкладки «Следственные отделы», «Зональные криминалисты», «Контроли».
- Импорт и экспорт контролей в Excel.
- Редактирование карточек контроля, пунктов задания, вложений.
- Сетевая синхронизация через общую папку.
- Управление справочником людей и инициаторов.

Если при запуске ОШИБКА «отсутствует api-ms-win-core-path-l1-1-0.dll»:
- в папке программы должен лежать файл api-ms-win-core-path-l1-1-0.dll
  (установщик кладёт его автоматически; стаб проекта
  nalexandru/api-ms-win-core-path-HACK, релиз 0.3.1);
- переустановите последнюю версию установщика или положите DLL вручную
  рядом с Порайонка_Админ_Web.exe.

Данные хранятся в папке:
%APPDATA%\porayonka\

При переустановке данные сохраняются.
