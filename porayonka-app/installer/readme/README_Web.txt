Порайонка v2.0 DARK final — Web-версия для Windows 7
======================================================

Установка:
1. Запустите Порайонка_Пользователь_Web_Setup.exe.
2. Выберите папку установки (по умолчанию C:\Program Files\Порайонка_Web).
3. Введите своё ФИО — по нему будут подтягиваться ваши контроли.
4. Поставьте галочки: ярлык на рабочем столе, автозапуск, запуск после установки.

Как работает:
- При запуске поднимается локальный web-сервер и открывается браузер.
- Не закрывайте фоновое окно сервера, пока работаете с программой.
- Программа висит в системном трее и присылает уведомления о сроках.
- При нажатии на уведомление или значок в трее снова открывается браузер.

Редактирование контролей недоступно — только просмотр.

Данные хранятся в папке:
%APPDATA%\porayonka\

Удаление (раунд 38):
- Деинсталлятор полностью убирает папку установки программы, ярлыки и
  запись автозапуска.
- Перед удалением останавливается процесс ТОЛЬКО этой редакции
  (точное имя exe; системный python.exe и другие программы не трогаются).
- В конце деинсталляции будет задан ЯВНЫЙ вопрос «Удалить локальные
  данные и резервные копии» про папку %APPDATA%\porayonka (кэш данных,
  локальные копии вложений, ежедневные резервные копии). По умолчанию
  — НЕТ (данные сохраняются). Если рядом установлены другие редакции
  «Порайонки», помните: эта папка у них ОБЩАЯ.
- Тихая деинсталляция (/SILENT, /VERYSILENT) НИКОГДА не удаляет
  %APPDATA%\porayonka (детерминированно: данные сохраняются).
- Общая сетевая папка (workspace) не удаляется НИКОГДА.
