# 🏛️ Порайонка v1.0

**Трекер статусов следственных отделов СК РФ (Ростовская область)**

---

## 🚀 Быстрый старт

### Вариант 1: Готовый .exe (для пользователей)
1. Скачайте `Porayonka.exe` из папки `dist/`
2. Запустите двойным кликом
3. **Python устанавливать не нужно!**

### Вариант 2: Запуск из исходников (для разработчиков)
```bash
# Установить зависимости
pip install -r requirements.txt

# Запустить приложение
python main.py
```

### Вариант 3: Сборка .exe (для новичков)
1. Убедитесь, что установлен Python 3.10+
2. Запустите файл `build_exe.bat` двойным кликом
3. Дождитесь окончания (3-7 минут)
4. Готовый `.exe` появится в папке `dist/`

## 🎮 Руководство пользователя

### Переключение статуса отдела
1. Найдите нужный отдел в таблице
2. Кликните по ячейке в столбце **«СТАТУС»**
3. Статус переключится по кругу:

```
⬜ Не получено  →  ✅ Получено  →  🔄 В работе  →  ⬜ Не получено
```

4. Данные сохранятся **автоматически**

### Поиск отдела
1. Введите часть названия в поле **«Поиск по отделам...»**
2. Таблица отфильтруется мгновенно
3. Нажмите **✕** для сброса фильтра

### Ручное сохранение
- Нажмите кнопку **💾 Сохранить** (синяя)
- Появится уведомление «Данные сохранены»
- Дата в шапке обновится

### Экспорт данных
1. Нажмите **📤 Экспорт** (зелёная кнопка)
2. Выберите формат:
   - **📊 Excel** — открывается в Microsoft Excel / LibreOffice
   - **🖨️ HTML** — откроется в браузере, Ctrl+P для печати
3. Файл сохранится в папку **«Загрузки»**

### Сброс всех статусов
1. Нажмите кнопку **🔄** (маленькая, справа)
2. Прочитайте предупреждение
3. Нажмите **«Сбросить»** для подтверждения
4. Все статусы вернутся к состоянию «Не получено»

## ❓ Решение проблем

### Приложение не запускается
**Причина:** Не установлен Microsoft Visual C++ Redistributable

**Решение:**
1. Скачайте: https://aka.ms/vs/17/release/vc_redist.x64.exe
2. Установите и перезагрузите компьютер

---

### Данные не сохраняются
**Причина:** Нет прав на запись в `%APPDATA%`

**Решение:**
- Запустите от имени администратора (правый клик → «Запуск от имени администратора»)

---

### Экспорт в Excel не открывается
**Причина:** Файл уже открыт в Excel

**Решение:**
- Закройте все окна Excel
- Повторите экспорт

---

### Ошибка при сборке .exe
**Причина:** Конфликт версий flet

**Решение:**
```bash
pip uninstall flet -y
pip install flet>=0.25.0
```
Затем снова запустите `build_exe.bat`

---

### «Белый экран» при запуске
**Причина:** Возможно повреждён файл данных

**Решение:**
1. Откройте `%APPDATA%\porayonka\`
2. Удалите или переименуйте `departments.json`
3. Перезапустите приложение (данные создадутся заново)
