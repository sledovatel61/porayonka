Вкладка «Контроли»

Автономные HTML-прототипы третьей вкладки приложения «Порайонка». Все файлы работают офлайн: достаточно открыть любой из них в браузере.

Серия 1 — варианты раскладки

5 мокапов
Excel-Pro Классическая таблица с фильтрами по колонкам. Близко к текущей Excel-схеме, но в современном виде. Открыть мокап Master-Detail Список контролей слева, детальная карточка с пунктами и сроками справа. Открыть мокап Cards Grid Карточная сетка: каждый контроль — отдельная плитка со статусом, сроком и исполнителями. Открыть мокап Deadline Board Kanban-доска по срокам: просрочено, сегодня, скоро, в работе, исполнено. Открыть мокап Command Center Дашборд сверху + таблица + выдвижная панель детализации.
