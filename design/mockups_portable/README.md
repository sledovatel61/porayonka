## 01 — Excel-Pro

**Файл:** `01_excel_pro.html`

**Суть:** Классическая таблица с липкой шапкой и отдельной строкой фильтров под каждым столбцом (в стиле Excel).

**Особенности:**
- Зебра + hover
- Фильтры по каждой колонке
- Плотная компактная раскладка
- Полноценная модальная карточка контроля с календарем

**Плюсы:** Максимальная плотность и читаемость для опытных пользователей.

## 02 — Master-Detail

**Файл:** `02_master_detail.html`

**Суть:** 35% ширины — компактный список слева, 65% — детальная панель справа с инлайн-редактированием.

**Особенности:**
- Поиск + фильтры-пилюли
- Инлайн-редактирование в правой панели

**Плюсы:** Лучший баланс скорости и удобства.

## 03 — Карточки-сетка

**Файл:** `03_cards_grid.html`

**Суть:** Плитки контролей в стиле карточек (6 в ряд). Цветная статусная полоса сверху.

- Фильтры-пилюли сверху
- Полноценная карточка редактирования

**Плюсы:** Хорошая визуальная иерархия.

## 04 — Дедлайн-доска

## Серия v2 (скины) — визуальные стили вкладки «Контроли»

**Папка:** `v2/`

Создано 5 автономных HTML-мокапов с одинаковой структурой `Excel-Pro`, различающихся только визуальным стилем (скином). Все скины воспроизводимы в Flet 0.23.2: сплошные цвета, `border`, `border_radius`, полупрозрачные заливки (`#hex22`), моноширинный шрифт. Градиент разрешён только на крупной статичной шапке (отмечен комментарием в коде). Без `backdrop-filter`, без теней на мелких элементах в скролле.

### Скины

| Файл | Название | Характер | Ключевые визуальные решения |
|---|---|---|---|
| `01_midnight_gold.html` | Midnight Gold | Глубокий тёмно-синий + золото | Градиентная шапка, золотая обводка (`#d4af37`), полупрозрачная заливка `#d4af3722`, солидный «гос» вид |
| `02_emerald_ops.html` | Emerald Ops | Оперативный зелёный пульт | Зелёный фон (`#061a12`), изумрудный акцент (`#10b981`), светящиеся зелёные обводки на активных элементах |
| `03_graphite_hc.html` | Graphite HC (high contrast) | Максимальная читаемость | Почти чёрный, белый текст, яркие статусные цвета (`#ff2a2a`/`#ffe600`/`#00e676`), радиус 4px, границы 2px, шрифты `W_900` |
| `04_modern_saas.html` | Modern SaaS | Фиолетово-индиго, воздух, мягкость | Нейтральные zinc (`#18181b`), фиолетовый акцент (`#6366f1`), мягкие радиусы 14px, прозрачные заливки `#6366f122` |
| `05_amber_terminal.html` | Amber Terminal | IDE-стиль, дата-денс | Янтарный акцент (`#ffb000`), моноширинный шрифт (`Consolas`) для цифр/дат, компактная таблица, янтарное свечение |

Каждый мокап содержит:
- Таблицу с фильтрами в шапке (структура `Excel-Pro`)
- Карточку-оверлей (секция с календарём августа 2026)
- Русский календарь с выбранным днём
- Блок-свотч палитры с hex-кодами в углу страницы

**Обзорная страница:** `v2/index.html` — превью всех 5 скинов с ссылками «Открыть».

**Рекомендация по «вау-эффекту» для реализации в Flet:**
- Используйте `bgcolor` с прозрачностью (например `#d4af3722`) для «свечения» статусов.
- Делайте активные строки через `border=ft.border.only(...)` с акцентным цветом.
- Градиентную шапку — только один `Container` с `gradient=ft.LinearGradient(...)` в верхней части вкладки.
- Не добавляйте `backdrop-filter` или сложные тени в скроллируемые списки — это не воспроизводимо.

## Серия v3 — премиальные скины Excel-Pro

**Папка:** `v3/` · **обзор:** `v3/index.html`

Это шесть самостоятельных визуальных направлений на общей полной раскладке: двухстрочная шапка таблицы с фильтрами в каждой колонке, реальные записи, статусы, hover-состояния, полноэкранная рабочая карточка и полный календарь августа 2026. Палитра каждого направления вынесена в нижнюю строку и не закрывает данные.

| Файл | Скин | Характер |
|---|---|---|
| `v3/01_graphite_pro.html` | Graphite Pro | Сдержанная инженерная рабочая среда в духе GitHub Dark. |
| `v3/02_vercel_geist.html` | Vercel / Geist | Контрастный минимализм, максимум воздуха и один синий акцент. |
| `v3/03_linear.html` | Linear | Мягкий тёмный интерфейс с индиго-навигацией и изящными pill-компонентами. |
| `v3/04_emerald_ops_premium.html` | Emerald Ops Premium | Строгий оперативный пульт с изумрудными статусными сигналами. |
| `v3/05_midnight_gold_premium.html` | Midnight Gold Premium | Серьёзная navy-подача с экономным золотым акцентом. |
| `v3/06_cobalt_archive.html` | Cobalt Archive | Более крупный архивный интерфейс для спокойного чтения и работы. |

### Рекомендация v3

**Основной кандидат — `01_graphite_pro.html`:** лучше всего выдерживает плотную таблицу, не отвлекает от сроков и хорошо переносится на Flet-компоненты.

**Альтернатива для руководящего контура — `05_midnight_gold_premium.html`:** сохраняет деловую сдержанность, но даёт продукту более официальный, законченный характер без декоративного перегруза.
