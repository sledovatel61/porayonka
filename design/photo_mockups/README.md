# Фото-мокапы вкладки «Контроли» — 10 направлений дизайна

> Полноэкранные PNG 1600×900 • тёмная тема • эталоны стиля для реализации в Flet
> (перенос палитр в `porayonka-app/core/constants.py`)

## Как сделаны эти картинки

1. **Скрины реального состояния программы** (`ref/`): запущено реальное Flet-приложение
   «Порайонка» (ветка `main`, `porayonka-app/`) в headless Chromium, вкладка «Контроли»
   с реальными данными — 134 контроля, из них Просрочено 2, Сегодня 2, Скоро 5,
   В работе 114, Исполнено 9 (файл данных `controls.json`, дата сохранения 04.08.2026):
   - `ref/real_controls_tab.png` — вкладка «Контроли», список;
   - `ref/real_controls_card.png` — то же с открытой карточкой контроля;
   - `ref/real_tab1.png` — вкладка «Следственные отделы» (контекст).
2. **Генерация мокапов**: 9 из 10 вариантов сгенерированы нейросетью (Gemini image model)
   по этим реальным скринам как референсу — сохранены состав экрана, данные и тексты.
3. **Вариант 06 (Aurora Gradient)** — фотореалистичный HTML-рендер по той же раскладке
   реального приложения (снят скриншотом headless Chromium): градиент на шапке — как раз
   то, что можно и нужно будет сделать в Flet одним `LinearGradient`-контейнером.
   Это запасной путь из промпта («если нет генератора — HTML-рендеры»), здесь он применён
   осознанно: у нейросети закончился лимит генераций на сессию, а вариант вышел слишком светлым.

> ⚠️ У AI-картинок мелкие надписи могут быть слегка искажены — это нормально для фото-эталонов:
> в реализации текст всегда будет настоящим (шрифты системы). Крупные заголовки и статусы
> во всех вариантах читаемы. **Стилевая карточка ниже — источник истины для реализации**,
> а не пиксели картинки.

## 01 · Glass Dark

**Файл:** `01_glass_dark.png` (с открытой карточкой контроля)

**Характер:** глубокий синий фон, матовые «стеклянные» панели с тонкими светлыми кромками,
мягкое свечение активных элементов. Дорогой тёмный интерфейс «премиум-класса»; таблица —
как полупрозрачные стеклянные карточки.

**Стилевая карточка:**

| Роль | Hex |
|---|---|
| Фон | `#0a1024` |
| Поверхность (стекло) | `#16213d` (в Flet — `#16213dcc`, alpha для эффекта стекла) |
| Границы | `#ffffff1a` (белый 10%), светлая кромка сверху панелей — `#ffffff2e` |
| Текст | `#f2f5ff` |
| Вторичный текст | `#93a3c7` |
| Приглушённый | `#5d6b8f` |
| Акцент | `#4f8cff` |
| Просрочено / Сегодня / Скоро / В работе / Исполнено / Завершён | `#ff5c6e` / `#ffd166` / `#ff9f43` / `#2fd08b` / `#8a94ad` / `#4f8cff` |

- Радиусы: 10–14 px; плотность: средняя; шрифт: Inter / Segoe UI.
- Реализация в Flet: «стекло» — только крупные панели (шапка, тулбар, карточка) с
  полупрозрачным `bgcolor`; без `backdrop-filter`. Светлые кромки — `border=ft.border.only(top=…)`.
- Свечение статусов: заливка `#ff5c6e22` + акцентная рамка 1px.

## Рекомендация

**Рекомендую №1 — `01 Glass Dark`:** максимальный «вау» при умеренной сложности.
Стекло имитируется полупрозрачными заливками и светлыми кромками (это Flet умеет),
тёмно-синяя гамма близка к текущей, а статусы остаются контрастными. Идеален как флагманский
скин для вкладки «Контроли».

**Рекомендую №2 — `03 Premium Gov`:** тематически точный для Следственного комитета —
солидный, строгий, «государственный». Хорошо смотрится рядом с существующими вкладками
и прост в реализации (золото — только в акцентах).

**Рекомендую №3 — `04 Minimal Light-Dark`:** самый безопасный и дешёвый: почти нечего
ломать, отличная читаемость, современный вид. Хороший «рабочий» скин по умолчанию.

**Запасной — `09 High Contrast Pro`:** если важна работа на старых мониторах/Windows 7
(в проекте есть `Porayonka_Win7.spec`) — это единственный вариант без полупрозрачностей
и теней, с гарантированным контрастом.

*Полный состав экрана (шапка, чипы, фильтры, таблица, статусы) одинаков во всех вариантах
и повторяет реальное состояние приложения — см. `ref/`.*
