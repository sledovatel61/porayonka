## 2. Задачи раунда 14

### 2.1 Hover — вернуть мгновенный

- Вернуть подсветку строки таблицы при наведении.
- Подсветка должна реаговать **мгновенно** и не оставлять «хвостов»
  (несколько подсвеченных строк одновременно).
- Рекомендуемый вариант: **акцентная рамка 1 px** (`GLASS["accent"]` = `#4f8cff`) +
  лёгкая смена фона (`GLASS["hover_bg"]` = `#2c3650`).
- Запрещено:
  - `animate`, `animate_scale`, `animate_opacity`;
  - `shadow` / `BoxShadow`;
  - `gradient`;
  - троттлинг (`throttle`) событий;
  - тяжёлые операции внутри `on_hover` (print, traceback, пересоздание контролов);
  - `on_hover` на вложенных контролах внутри строки (иконки, кнопки, текст).
- Правильный паттерн: один обработчик на весь `ft.Container` строки, который
  меняет только `bgcolor`/`border` и вызывает `_safe_update()`.
- См. также `AGENTS мангуст.md` в корне репозитория — там в проекте на tkinter
  решалась похожая проблема hover/scroll. Важные идеи:
  - лёгкий hover только рамкой/полоской, без заливки всей строки;
  - не вешать `on_hover` на вложенные контролы;
  - не вызывать `print`/`traceback` в горячем обработчике;
  - debounce применим только к тяжёлым операциям, а не к самому hover-эффекту.

### 2.2 Таблица — шире, но помещается

- Увеличить дефолтные ширины колонок по сравнению с раундом 13,
  но сохранить сумму ≤ **1240 px** при ширине окна **1280 px**
  (чтобы колонка «Действия» не уезжала за экран).
- Действия (кнопки строки) должны оставаться прижаты к правому краю, но не
  «впиваться» в границу окна.
- На широком экране (~1900 px) flex-колонки («Содержание», «Исполнители»)
  могут расти, но с разумным лимитом (~480 / 220 px). Желательно, чтобы
  таблица не выглядела «собранной в кучу» посередине экрана.
- Вернуть кегль строк до 12–13 px (сейчас 11 px — мелковато).
- Сохранить кламп сохранённых `col_widths` из `controls_settings.json`:
  если пользователь раньше растянул колонки, при следующем запуске ширины
  не должны превышать бюджет окна.

### 2.3 Справочники — resize + плавный скролл

- Вернуть возможность растягивать окно «Справочники» мышью за правый нижний угол

- Уменьшить шаг прокрутки колесом мыши в списках исполнителей и инициаторов
  до **1–2 строк за щелчок**. Сейчас прокрутка слишком большая.
- Сохранить уже работающее редактирование и сохранение записей (раунд 13):
  `extra_people`, `hidden_people`, `custom_initiators`, `init_renames`,
  `hidden_init_groups`.
- Окно справочников должно оставаться overlay-Container (не AlertDialog).

### 2.4 Карточка контроля — скруглённые углы

- Вернуть скругление углов карточки контроля.
- В раунде 12 (агент 2, `arena/019feacf-porayonka`, коммит `303fb52`) углы были

- Обязательно:
  - равномерная рамка `ft.border.all(1, GLASS["border"])`;
  - `border_radius=16`;
  - `clip_behavior=ft.ClipBehavior.HARD_EDGE`;
  - никакого `border.only` с разной толщиной сторон (причина прозрачных углов).
- Не ломать остальной layout карточки (две колонки, скролл, поля, inline-выбор

## 3. Технические ограничения

- **Flet строго 0.23.2.** Не повышать.
- **Внутри `Column(scroll=ft.ScrollMode.AUTO)`** запрещено:
  - `expand=True` (кроме горизонтальных спейсеров внутри `Row`);
  - `wrap=True`;
  - `animate*`, `gradient`, `shadow` / `BoxShadow` на мелких контейнерах.
- **Цвета 8-digit — только `#AARRGGBB`** (альфа первая). Не `#RRGGBBAA`.
  Динамические полупрозрачные: `f"#22{color[1:]}"`.
- **`print()` в консоль — только ASCII** (без русских букв, emoji, спецсимволов),
  чтобы избежать `UnicodeEncodeError` на Windows cp1251.
- **UI-текст (`text=...`) — на русском.**
- **Иконки — `ft.icons.*`**, не emoji.
- **Все `.update()` контролов** — через `_safe_update()` (хелпер уже есть в
  `controls_tab.py`). Исключение: горячие hover-обработчики — там `_safe_update`
  без печати ошибок.
- **Не ломать раунд 13:** сохранение справочников, прикрепление, таблица ≤1240 px,
    smoke ALL OK.
- **Не добавлять новых зависимостей.**
