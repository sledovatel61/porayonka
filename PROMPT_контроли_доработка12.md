## Цель

Исправить 5 проблем радикально и надёжно:

1. **Hover** — без задержек и без множественной подсветки.
2. **Таблица** — по умолчанию помещается в окно, колонка «Действия» не уезжает за край.

4. **Карточка контроля** — скруглённые углы (не прозрачные, не прямоугольные); поле «За кем контроль» всегда заполнено.
5. **Прикрепление файла** — сразу отображается в карточке после выбора.

## Задача 1 — Hover: убрать лаг и множественную подсветку

**Проблема:** при движении курсором подсвечивается несколько строк сразу, с задержкой.

**Решение (выбери ОДНО, главное — работает в GUI):**
- **Вариант А (предпочтительный):** убрать hover-заливку фона строки полностью. Вместо этого при наведении менять только **рамку строки** (border color на акцент `#4f8cff`, толщина 1px). При leave возвращать исходную рамку. Если и это лагает — перейти к варианту Б.
- **Вариант Б:** убрать вообще любой hover-эффект на строках, оставить только `mouse_cursor=CLICK`. Это гарантированно убирает лаг.
- **Запрещено:** оставлять hover-заливку фона с `row.update()` — это даёт задержку и «хвосты».

**Требование:** при быстром проведении курсором по таблице не должно оставаться подсвеченных строк.

## Задача 2 — Таблица по умолчанию помещается на экран

**Проблема:** даже при ширине окна ~1900 px таблица не помещается, колонка «Действия» уезжает за край (см. `Таблица не поместилась.png`).

**Решение:**
- Пересмотреть все дефолтные ширины колонок. Цель: при ширине окна **≥1280 px** таблица целиком видна без горизонтального скролла.
- Уменьшить ширину следующих колонок (ориентировочно):
  - «Вх. №» — до 130–140 px
  - «Дата поступления» — до 85 px
  - «Инициатор» — до 100 px
  - «За кем» — до 100 px
  - «Тип» — до 75 px
  - «Срок исполн.» — до 90 px
  - «Статус» — до 100 px
  - «Действия» — до 90–100 px (4 иконки по 20–22 px)
  - «Исполнители» и «Содержание» — занимают оставшееся пространство, но **не больше** чем осталось.
- Важно: не просто задать сумму 1280, а учесть **все отступы, spacing, разделители, scrollbar** (~40–60 px запас).
- Если таблица всё равно не помещается — разрешено уменьшить кегль текста в строках до 11 px.
- Колонка «Действия» остаётся прижата к правому краю.

**Как проверить в headless:** smoke-тест должен проверять, что сумма ширин колонок + padding + spacing ≤ 1240 px при page.width=1280.

## Задача 3 — Справочники: resize + построчный скролл

**Проблема:** модалка «Справочники» не растягивается, скролл пролистывает сразу много элементов (см. `Справочник.png`).

**Решение:**
- **Переделать модалку «Справочники» из `ft.AlertDialog` в overlay-Container** (по аналогии с карточкой контроля). Только так в Flet 0.23.2 можно реализовать произвольный resize.
  - Overlay затемнённый фон + панель по центру.
  - Панель имеет min/max размеры и resize-зону в правом нижнем углу.
  - При растягивании окна панель увеличивается, списки тянутся.
- Для построчного скролла:
  - использовать `ft.ListView` с `item_extent` равным высоте одной строки;
  - или `ft.Column` с `scroll=ft.ScrollMode.AUTO` и фиксированной высотой строки, но **без больших padding/margin**, чтобы колесо мыши не «прыгало».
  - если `ListView` в Flet 0.23.2 всё равно пролистывает страницами — добавить обработчик `on_scroll` с `e.scroll_y` и программно прокручивать на `item_extent` за раз.

## Задача 4 — Карточка: скруглённые углы + поле «За кем контроль»

**Проблема:**
- Углы карточки не скруглены, выглядят прямоугольными/прозрачными с контуром.
- Для контроля 4239-26 поле «За кем контроль» пустое, хотя в таблице стоит «Чащин Э.А.».

**Решение для углов:**
- Гарантированный способ: сделать `detail_card` **единым внешним `ft.Container`** с:
  - `border_radius=16`
  - `clip_behavior=ft.ClipBehavior.HARD_EDGE`
  - `border=ft.border.all(1, GLASS["border"])`
- Внутри `detail_card` — `ft.Column` с содержимым. **Все дочерние элементы должны иметь меньшую ширину/высоту**, чем `detail_card`, чтобы не вылезать за границы.
- Если resize-handle в `Stack` ломает clip — перенести handle **внутрь** `detail_card` (в правый нижний угол) как дочерний `ft.Container` с `alignment=ft.alignment.bottom_right`. Или временно убрать resize-handle ради рабочих углов (resize можно вернуть позже).
- Если `Stack` с `detail_overlay` мешает clip — обернуть карточку в дополнительный `ft.Container(clip_behavior=HARD_EDGE)`.

**Решение для «За кем контроль»:**
- При открытии карточки значение контролёра должно устанавливаться всегда, если оно не пустое.
- Если точное совпадение с `available_names` отсутствует — искать **по фамилии** (первое слово) среди канонических имён.
- Если не нашлось — добавить значение из данных как временную опцию dropdown и выбрать её.
- Ни в коем случае не оставлять поле пустым, если в таблице есть значение.

## Задача 5 — Прикрепление файла: сразу видно

**Проблема:** после выбора файла toast «Файл прикреплён» показывается, но вложение не появляется в списке (см. `прикрепление фото.png`).

**Решение:**
- После FilePicker `on_result` выполнить строго последовательно:
  1. `copy_attachment_to_local(control_id, path)`
  2. Добавить относительный путь в `control.attachments` и в `detail_state["attachments"]`.
  3. Вызвать `_rebuild_attach()`.
  4. Вызвать `_safe_update(attach_col)`.
  5. Вызвать `_persist()` (или `save_controls`) — сохранить `controls.json`.
  6. `page.update()` (если нужно).
  7. Toast.
- Если `attach_col` не обновляется — принудительно очистить `attach_col.controls` и пересоздать заново.
- Проверить, что `FilePicker` result handler действительно подключён к правому пикеру (`_controls_attach_picker`), а не к экспортному/импортному.

## Технические ограничения

- Flet 0.23.2 — не повышать.
- Внутри `Column(scroll=ft.ScrollMode.AUTO)` — никаких `expand=True` (кроме горизонтальных спейсеров в `Row`), `wrap=True`, `animate*`, `shadow`, `gradient` на мелких контейнерах.
- Цвета с прозрачностью — только `#AARRGGBB`. Динамические — через `with_alpha` из `glass_theme.py`.
- `print()` в консоль — только ASCII.
- UI-текст — на русском; `ft.icons.*`.
- Не ломать логику данных, сеть, Excel, архив, другие вкладки.
- Вложенные `AlertDialog` запрещены.
