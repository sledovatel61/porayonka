## Цели раунда 16

### 1. Тонкая левая статусная полоса (не цветная колонка «№»)

- Левая полоса должна быть **строго 4 px** и **полной высоты строки** (не 28 px по центру).
- Цвет полосы — по статусу контроля (`overdue`/`today`/`soon`/`in_progress`/`done`/`completed`/`none`).
- Номер строки (`№`) должен быть на **нейтральном фоне плашки** (`#2a3247`), а не на цветном фоне.
- Колонка «bar» **не должна быть ресайзабельной** и **не должна сохраняться** в `col_widths`.
- Если в текущих `settings["col_widths"]` уже сохранено большое значение для `bar` — сбросить его на 4 при старте и не сохранять обратно.
- Скрин, что должно получиться: аккуратная цветная полоса 4 px слева, номер строки серый.

### 2. Исправить ошибки скролла (`KeyError: 'sd'` / `'dir'`)

- Причина: `Column.on_scroll = _make_row_scroller(...)` в списках «Справочников» (см. `porayonka-app/ui/controls/controls_tab.py`, функция `_make_row_scroller`). В Flet 0.23.2 `scroll_to(...)` порождает событие скролла с неполным payload, и `OnScrollEvent` падает с `KeyError` до того, как доходит до нашего обработчика.
- **Решение:** заменить кастомный `_make_row_scroller` на что-то нативное и безопасное, например:
  - `ft.ListView` с `item_extent=32` (или высота строки) для списков исполнителей/инициаторов — тогда колесо будет листать по строкам без кастомного `on_scroll`;
  - либо убрать `on_scroll` у `Column` и принять нативный шаг, но тогда добавить `ft.Scrollbar` явно.
- Главное: **в консоли не должно быть ни одной `KeyError: 'sd'`/`'dir'`** после открытия/скролла/закрытия «Справочников».

### 3. Плавный скролл списков в «Справочниках» + scrollbar

- Один щелчок колеса мыши — **1–2 строки** (не страница).
- Добавить **видимый бегунок справа** (Flutter Scrollbar на десктопе). Если `ft.ListView` используется, бегунок появляется сам при `scroll=ft.ScrollMode.AUTO`; если остаётся `Column`, нужно добавить `ft.Scrollbar` через `ft.Column(..., scroll=ft.ScrollMode.AUTO)` — но в Flet 0.23.2 scrollbar для Column может не показываться, поэтому `ListView` предпочтительнее.
- Строки в списках: высота 32 px, spacing 2 px, как сейчас.

### 4. Запоминать размеры карточки и «Справочников»

- **Карточка контроля:** уже есть `state["card_w"]`/`state["card_h"]` и `_on_drag_end` сохраняет в `settings["card_width"]`/`settings["card_height"]`. Убедиться, что:
  - при открытии карточка берёт сохранённые размеры;
  - при растягивании размеры сохраняются **сразу** (или по окончании drag) и применяются при следующем открытии;
  - если сохранённых размеров нет — использовать дефолтные `920×780`.
- **Модалка «Справочники»:** добавить аналогичную логику:
  - `settings["refs_width"]` и `settings["refs_height"]`;
  - при открытии использовать сохранённые значения (или дефолт `680×560`);
  - при drag-ресайзе хэндла обновлять `refs_width`/`refs_height` в `state` и сохранять в `settings`.
- Для минимизации: `min_w=480`, `min_h=420` (или разумные пределы, чтобы не схлопнуть в 0).

## Технические ограничения

- **Flet строго 0.23.2.** Не повышать.
- **Цвета 8-hex** — только `#AARRGGBB` (альфа первая). Динамические прозрачные через `with_alpha(color, "22")` → `#22RRGGBB`. См. `ui/controls/glass_theme.py`.
- **Внутри `Column(scroll=ft.ScrollMode.AUTO)`** — никаких `expand=True` (кроме горизонтальных спейсеров в `Row`), `wrap=True`, `animate*`, `gradient`, `shadow` на мелких контейнерах.
- **Рамки с `border_radius`** — равномерная толщина всех сторон (не `border.only` с разной толщиной).
- **`print()`** — только ASCII, без русских букв/emoji; **UI-текст** — на русском.
- **`ft.icons.*`** вместо emoji.
- Все `.update()` контролов — через `_safe_update()` (исключение — горячие hover, там `_quiet_update`).
