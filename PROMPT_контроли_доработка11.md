## Цель

Исправить 5 замечаний после раунда 10:

1. Hover строк таблицы — без задержек и **только одна строка** подсвечена.
2. Таблица по умолчанию должна помещаться на экран (колонка «Действия» не уезжает за край).
3. Модалка «Справочники» — растягивается окном + скролл по одному элементу.
4. Карточка контроля — углы скруглены (не прозрачные/не прямоугольные) + поле «За кем контроль» должно заполняться из данных строки.
5. Прикрепление файла — сразу отображается в карточке после выбора, без сохранения/переоткрытия.

## Задача 1 — Hover: одна строка, без задержек

**Проблема:** сейчас при движении курсора подсвечиваются несколько строк сразу, и с задержкой (см. `hover.png`).

**Что нужно:**
- При наведении на строку подсвечена **только она одна**; предыдущая строка сразу сбрасывается.
- Без видимой задержки.
- Если текущий подход с `row.on_hover` + `row.update()` в Flet 0.23.2 не позволяет этого — допустимо упростить hover до:
  - только смены курсора (`mouse_cursor=CLICK`) и **без заливки фона**;
  - или hover только на левой статусной полосе (она уже есть);
  - или любого другого минимального решения, где не будет ни множественной подсветки, ни лага.
- Строка остаётся кликабельной.

**Куда смотреть:** `porayonka-app/ui/controls/controls_tab.py`, `_build_row`, `on_hover`, throttle-логика.

## Задача 2 — Таблица по умолчанию помещается на экран

**Проблема:** после выравнивания «Действия» вправо колонка уехала за правый край экрана, пришлось вручную двигать «Содержание» (см. `Колонка действия.png`).

**Что нужно:**
- Подобрать дефолтные ширины колонок так, чтобы при ширине окна **≥1280 px** вся таблица помещалась по ширине без горизонтального скролла.
- Колонка «Действия» должна оставаться прижатой к правому краю (это уже сделано — не ломать).
- Если не хватает места, сжимать прежде всего «Содержание» и «Исполнители»; «Вх. №», «Дата поступления», «Инициатор» — минимально необходимые.
- Ширины по умолчанию задать в `controls_settings.json` (`col_widths`) и/или в коде `_DEFAULT_WIDTHS`.
- Пользователь не должен вручную двигать колонки после запуска.

**Куда смотреть:** `porayonka-app/ui/controls/controls_tab.py`, `_DEFAULT_WIDTHS`, `_layout_widths`, `_rebuild_header`, `_build_row`.

## Задача 3 — Модалка «Справочники»: resize + скролл по элементу

**Проблема:**
- Окно справочников нельзя растянуть.
- Скролл пролистывает сразу на страницу, пропуская элементы (см. `Справочник.png`, `Справочник2.png`).

**Что нужно:**
- Модалку можно растягивать за правый нижний угол (drag-зона, как у карточки контроля) или хотя бы за края окна.
- Скролл внутри списков должен листать **по одному элементу**, а не по странице. Проверить/убрать `page_size` у `ListView`/`GridView`/`Column` со scroll, если он влияет.
- Содержимое списков уже на всю ширину (раунд 10) — сохранить.

**Куда смотреть:** `porayonka-app/ui/controls/controls_tab.py`, `_open_references`, `_build_ref_list`, `ListView`/`Column(scroll=AUTO)`.

## Задача 4 — Карточка: скруглённые углы + заполненное поле «За кем контроль»

**Проблема:**
- На скрине `Карточка.png` углы карточки **прозрачные с контуром**, скругление не применяется.
- В таблице у контроля «4239-26» исполнитель Гайнутдинов, контроль за Чащиным, но в карточке поле «За кем контроль» пустое/не выбрано.

**Что нужно:**
- Скруглить все 4 угла карточки. В раунде 10 добавлен `clip_behavior=ft.ClipBehavior.HARD_EDGE`, но видимо недостаточно. Возможные пути:
  - убедиться, что `detail_card` — это самый внешний `Container` с `border_radius` и `clip_behavior`;
  - если дочерний `Column`/`Row` выходит за границы из-за `expand` или отрицательных margin — убрать;
  - добавить промежуточный `Container` с фиксированным border_radius и clip_behavior вокруг контента;
  - или отказаться от `Stack` с абсолютным позиционированием resize-handle, если он ломает clip.
- Поле «За кем контроль» (`controller_dd`) при открытии карточки должно содержать значение `control.controller` из данных строки. Если контролёр есть в таблице, он должен быть выбран в dropdown.

**Куда смотреть:** `porayonka-app/ui/controls/controls_tab.py`, `_open_detail`, `detail_card`, `controller_dd`, `controller_field`, `_build_controller_row`.

## Задача 5 — Прикрепление файла: сразу видно в карточке

**Проблема:** после прикрепления файла (`Прикрепить файл` → выбор) появляется toast «Сохранено», но вложение не отображается в списке вложений карточки. Нужно сохранить, закрыть, открыть заново — только тогда видно (см. `Прикрепление.png`, `Прикрепление2.png`).

**Что нужно:**
- После успешного выбора файла в FilePicker сразу:
  - скопировать файл в папку вложений;
  - добавить путь в `control.attachments`;
  - вызвать `_rebuild_attach()` или аналогичный метод для обновления списка вложений в UI;
  - сохранить `controls.json`;
  - toast «Файл прикреплён».
- Не требовать сохранения/переоткрытия карточки.

**Куда смотреть:** `porayonka-app/ui/controls/controls_tab.py`, `_rebuild_attach`, FilePicker handler для вложений, `_on_attach_result`.

## Технические ограничения (обязательны)

- Flet 0.23.2 — не повышать.
- Внутри `Column(scroll=ft.ScrollMode.AUTO)` — никаких `expand=True` (кроме горизонтальных спейсеров в `Row`), `wrap=True`, `animate*`, `shadow`, `gradient` на мелких контейнерах.
- Цвета с прозрачностью — только `#AARRGGBB`. Динамические — через `with_alpha` из `glass_theme.py`.
- `print()` в консоль — только ASCII (без русских букв, emoji, спецсимволов).
- UI-текст (`text=...`) — на русском.
- `ft.icons.*` вместо emoji.
- Все `.update()` контролов через `_safe_update()`.
- Не ломать логику данных, сеть, Excel, архив, другие вкладки.
- Вложенные `AlertDialog` запрещены.
