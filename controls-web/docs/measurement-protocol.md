## Правила измерений

1. Не менее **30 повторов** для каждого измеряемого действия;warmup-запросы (3) в статистику не входят.
2. Отчёт по **p50 и p95**, плюс min/max/среднее. Метод процента: ближайший ранг
   (`index = round(p/100 * (n-1))`).
3. Фиксируются два времени: полное (клиент + сеть + сервер) и серверное (заголовок `X-Process-Time-Ms`).
4. Перед измерениями фиксируются параметры среды: ОС, ядра CPU, RAM, версия Python, версия PostgreSQL,
   версия приложения, git SHA, состав и sha256 ассетов сборки.
5. Измерения проводятся на полном объёме данных (10 000 записей), а не на урезанной выборке.
6. Для Win7-проверки дополнительно фиксируются: модель ПК, CPU, RAM, разрешение, масштаб, версия и
   разрядность браузера, тип сети и задержка до сервера, объём данных, SHA сборки, дата/время, исполнитель.

## Сценарии серверных измерений

`список_страница_1`, `список_страница_100`, `список_страница_200`, `поиск_по_номеру`,
`поиск_по_содержанию_кириллица`, `поиск_широкий_термин`, `карточка_записи`, `сводные_счётчики`,
`живость_health`, `статика_index_html`, `статика_js_ассет`, `pdf_загрузка_кириллическое_имя` (10 повторов),
`pdf_скачивание` (10 повторов), `pdf_sha256_совпадает`, `pdf_удаление_после_измерений`.

## Сценарии, которые обязан измерить Win7-протокол

Холодное открытие списка, поиск по номеру, поиск по кириллическому термину, переход на 5 страниц вперёд,
переход в конец списка, открытие карточки, скачивание PDF, загрузка PDF, поведение при потере связи,
память вкладки за 10 минут, плавность прокрутки. По каждому — секундомер и запись «получилось / не получилось».

## Команды

```bash
# серверные измерения (30 повторов, p50/p95)
backend/.venv/bin/python scripts/measure.py --repeats 30 --base http://127.0.0.1:8080
# результат: measurements/W01-measurements-<UTC>.md и .json
# копия для репозитория: docs/measurements-w01-sandbox.md
```
