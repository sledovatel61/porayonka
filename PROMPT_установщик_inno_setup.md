# ПРОМПТ АГЕНТУ: установщики Windows (Inno Setup)

## Репозиторий и база

- Репозиторий: `https://github.com/sledovatel61/porayonka.git` (ветка `main`).
- Приложение: `porayonka-app/main.py` и собранные portable-сборки в `porayonka-app/dist_all/`.
- Цель: создать **три установочных пакета** (`Setup.exe`) для Windows.

**Важно:** ты не должен править код самого приложения. Ты создаёшь только файлы установщика (Inno Setup `.iss`, картинки, батчики). Доработка web-версии, трея, пароля и т.д. — задача другого агента (см. `PROMPT_контроли_доработка_web_и_мелкие.md`). Ты ориентируешься на **готовые exe** и на `edition.json`, который установщик будет создавать/перезаписывать рядом с exe при установке.

## Что должно получиться

Три установочных файла:

1. `Порайонка_Админ_Setup.exe` — полная редакция.
2. `Порайонка_Пользователь_Setup.exe` — read-only, трей, уведомления, автозапуск.
3. `Порайонка_Пользователь_Web_Setup.exe` — для Windows 7, web-сервер + браузер, трей/уведомления (если будет готов другим агентом), автозапуск.

Итоговая папка: `porayonka-app/installer/` со скриптами, картинками и скриптом сборки `build_installers.bat`.

## Исходные файлы для установщика

Используй готовые portable-сборки, которые уже лежат в репозитории:

- `porayonka-app/dist_all/Порайонка_Админ/Порайонка_Админ.exe`
- `porayonka-app/dist_all/Порайонка_Админ/edition.json` (шаблон `{"role": "admin"}`)
- `porayonka-app/dist_all/Порайонка_Пользователь/Порайонка_Пользователь.exe`
- `porayonka-app/dist_all/Порайонка_Пользователь/edition.json` (шаблон `{"role": "user"}`)
- `porayonka-app/dist_all/Порайонка_Пользователь_Web/Порайонка_Пользователь_Web.exe`
- `porayonka-app/dist_all/Порайонка_Пользователь_Web/start_web_win7.bat`
- `porayonka-app/dist_all/Порайонка_Пользователь_Web/edition.json` (шаблон `{"role": "user"}`)
- `porayonka-app/assets/icon.png` и `porayonka-app/assets/icon.ico` (если нет ico, сгенерировать из PNG).
- `porayonka-app/assets/pig.wav` / `pig.mp3` (для звуков уведомлений, уже внутри exe, но можно положить рядом как fallback).

Если `dist_all/` отсутствует или неполная, агент может собрать portable exe через существующие `build_admin.bat` / `build_user.bat` / `build_user_web_win7.bat` (требуется Python + PyInstaller + Flet 0.23.2), но **приоритет** — использовать уже готовые файлы из `dist_all/`.

## Требования к каждому установщику

### Общие страницы и поведение

- Язык интерфейса: **русский**.
- Название продукта: **Порайонка**.
- Версия: **2.0 DARK final**.
- Издатель: **Следственный комитет РФ по Ростовской области** (или аналогичный официальный текст).
- Папка по умолчанию: `C:\Program Files\Порайонка\` для admin/user, `C:\Program Files\Порайонка_Web\` для web-версии (или предложить агенту удобный вариант).
- Поддержка `Program Files (x86)` и `Program Files` для x64.

### Страницы мастера установки

1. **Welcome** — приветствие, логотип, краткое описание.
2. **License** — лицензия (можно встроить простой текст MIT/службовый, не претендующий на юридическую силу; либо пустой placeholder `license.txt`).
3. **Select Destination Location** — выбор папки установки.
4. **Components / Custom Page** — галочки:
   - ✅ Создать ярлык на рабочем столе
   - ✅ Добавить в автозапуск Windows
   - ✅ Запустить приложение после установки
5. **Custom page для ввода данных** (зависит от редакции):
   - **Admin**: поле ввода пароля + повтор пароля. Записывается в `edition.json` рядом с exe.
   - **User / Web**: поле ввода ФИО пользователя (обязательно). Записывается в `edition.json` рядом с exe.
6. **Ready to Install** — сводка.
7. **Installing** — прогресс.
8. **Finish** — завершение, опционально запуск.

### Файлы, которые устанавливаются

**Admin:**
- `Порайонка_Админ.exe`
- `edition.json` с `{"role": "admin", "password": "<hash>"}` (если пользователь ввёл пароль; если оставил пустым — без поля `password`, приложение не спрашивает пароль).
- `README_Admin.txt` (краткая инструкция).

**User:**
- `Порайонка_Пользователь.exe`
- `edition.json` с `{"role": "user", "user_name": "ФИО пользователя"}`.
- `README_User.txt`.

**User Web:**
- `Порайонка_Пользователь_Web.exe`
- `start_web_win7.bat`
- `edition.json` с `{"role": "user", "user_name": "ФИО пользователя"}`.
- `README_Web.txt`.

### Ярлыки

- В меню **Пуск** → папка «Порайонка» → ярлык на приложение (и для web — на `start_web_win7.bat`).
- Опционально на **Рабочий стол** (по галочке).
- Для web-версии: ярлык запускает `start_web_win7.bat` (или exe, если другой агент доработает web-трей; адаптировать под оба варианта).

### Автозапуск

- Если пользователь поставил галочку «Добавить в автозапуск Windows», установщик прописывает ключ реестра:
  - `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Порайонка_Админ`
  - `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Порайонка_Пользователь`
  - `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Порайонка_Web`
- Значение: путь к установленному exe (для web — к `start_web_win7.bat` или к exe, если web-версия будет самостоятельной).
- Удаление при деинсталляции: автозапуск-ключи должны удаляться вместе с программой.

### Деинсталляция

- В Панели управления / «Приложения и возможности» должна появляться запись «Порайонка …».
- При удалении: удаляются файлы, ярлыки, автозапуск-ключи, реестр.
- Данные пользователя в `%APPDATA%\porayonka\` **не удаляются** (это важно — контроли и настройки должны сохраниться при переустановке).

## Визуальное оформление установщика

- **Иконка установщика**: `assets/icon.ico` (если нет — сгенерировать из `assets/icon.png`).
- **Иконка приложения** в ярлыках: тот же `icon.ico`.
- **Wizard image** (боковая картинка слева в мастере): создать PNG 164×314 (или рекомендуемые Inno Setup размеры) с тёмной темой, логотипом «Порайонка», версией.
- **Wizard small image** (картинка вверху): создать PNG 55×55 или 100×100.
- **Setup icon**: `icon.ico`.

Можно использовать простые сгенерированные картинки (например, через PIL/Pillow: тёмный фон, белый текст, логотип). Главное — аккуратно и в едином стиле.

## Структура файлов установщика

Предлагаемая структура в `porayonka-app/installer/`:

```
installer/
├── Common.iss                  # общие макросы, константы, функции
├── Admin.iss                   # установщик админской версии
├── User.iss                    # установщик пользовательской версии
├── UserWeb.iss                 # установщик web-версии для Win7
├── build_installers.bat        # сборка всех трёх .exe через iscc.exe
├── images/
│   ├── wizard_image.png        # боковая картинка
│   ├── wizard_small_image.png  # верхняя картинка
│   └── icon.ico                # иконка
├── readme/
│   ├── README_Admin.txt
│   ├── README_User.txt
│   └── README_Web.txt
└── license.txt                 # лицензия (placeholder)
```

## Скрипт сборки

`build_installers.bat` должен:

1. Найти `iscc.exe` (Inno Setup Compiler). Стандартные пути:
   - `C:\Program Files (x86)\Inno Setup 6\iscc.exe`
   - `C:\Program Files\Inno Setup 6\iscc.exe`
   - или взять из PATH.
2. Если не найден — вывести сообщение: «Установите Inno Setup 6 с jrsoftware.org/isinfo.php».
3. Скомпилировать три `.iss` в:
   - `installer\output\Порайонка_Админ_Setup.exe`
   - `installer\output\Порайонка_Пользователь_Setup.exe`
   - `installer\output\Порайонка_Пользователь_Web_Setup.exe`
4. Вывести итоговый список файлов.

## Пароль для admin-версии

- На странице ввода админского установщика: два поля «Пароль» и «Подтверждение пароля».
- Если пароли не совпадают — не давать продолжить установку.
- Хранить пароль в `edition.json` в виде простого хеша (например, SHA256 + соль). Не хранить plaintext.
- Если пользователь оставил поле пустым — не записывать поле `password` в `edition.json`, приложение не будет спрашивать пароль.
- Приложение (после доработки другим агентом) будет читать `edition.json` и проверять хеш.

**Формат `edition.json` для admin:**
```json
{
  "role": "admin",
  "password_hash": "sha256:..."
}
```

## ФИО для user/web-версий

- Поле ввода ФИО — обязательное.
- Проверка: не пустое, минимум 2 слова (Фамилия И.О. или полное ФИО).
- Записывать в `edition.json`:
```json
{
  "role": "user",
  "user_name": "Иванов И.И."
}
```

## Особенности web-версии

- Папка установки должна содержать и `exe`, и `start_web_win7.bat`.
- Ярлык в меню Пуск и автозапуск должны указывать на `start_web_win7.bat` **если** web-версия не доработана другим агентом для самостоятельного трея.
- Если web-версия будет доработана (трей внутри exe), можно использовать сам `exe`. Сделай скрипт гибким: константа в начале `.iss` (`UseStartBat=True/False`), чтобы легко переключить.
- В README_Web.txt объяснить: «Не закрывайте это окно, пока работаете с программой. Приложение висит в трее и присылает уведомления.»

## Проверка

Если на машине агента установлен Inno Setup 6:

```cmd
cd porayonka-app\installer
build_installers.bat
```

Должны создаться три `Setup.exe` в `installer\output\`.

Если Inno Setup не установлен:
- Убедиться, что `.iss`-файлы синтаксически корректны (правильные секции `[Setup]`, `[Files]`, `[Icons]`, `[Registry]`, `[Code]`, `[Run]`, `[UninstallRun]`, `[UninstallDelete]`).
- Проверить, что `build_installers.bat` корректно ищет `iscc.exe` и выводит понятные ошибки.
- Сгенерировать картинки и иконки.

## Что НЕ делать

- Не править код приложения (`main.py`, `controls_tab.py`, `edition.py` и т.д.).
- Не менять spec-файлы PyInstaller.
- Не добавлять зависимости в `requirements.txt` (Inno Setup — внешний инструмент, не Python).
- Не удалять существующие `dist_all/` и `build_*.bat`.

## Результат

- Ветка: `arena/XXXX-porayonka` (от `main`).
- Коммит с понятным сообщением.
- Пуш в `origin/arena/XXXX-porayonka`.
- Краткое резюме: что сделано, как собирать, что проверено, какие файлы получились.
- Если Inno Setup недоступен в среде агента — явно указать, что установку Inno Setup 6 и запуск `build_installers.bat` нужно выполнить на Windows-машине пользователя.
