# ПРОМПТ АГЕНТУ: доработка web-версии Win7 + user/admin вход + пароль + UI-мелочи

## Репозиторий и база

- Репозиторий: `https://github.com/sledovatel61/porayonka.git` (ветка `main`).
- Приложение: `porayonka-app/main.py`, `porayonka-app/main_web.py`.
- Запуск: `python porayonka-app/main.py`.
- Текущий раунд: **26** (продолжение раундов 20–25, результаты в `AGENTS.md` §§60–65).
- Версия Flet: **строго 0.23.2** (`flet==0.23.2` в `requirements.txt`).

## Контекст

Сейчас в `main` лежат три portable-сборки, собранные PyInstaller:
- `porayonka-app/dist_all/Порайонка_Админ/Порайонка_Админ.exe`
- `porayonka-app/dist_all/Порайонка_Пользователь/Порайонка_Пользователь.exe`
- `porayonka-app/dist_all/Порайонка_Пользователь_Web/Порайонка_Пользователь_Web.exe` + `start_web_win7.bat`

Пользователь готовит полноценный установщик Inno Setup отдельным агентом. **Твоя задача — только доработать код приложения**, чтобы web-версия и мелкие UX-моменты работали корректно. Установщик делает другой агент.

## Что нужно сделать

### 1. Web-версия (Win7) не запускается из frozen exe

**Симптом:** при запуске `Порайонка_Пользователь_Web.exe` падает:

```
AttributeError: 'NoneType' object has no attribute 'isatty'
ValueError: Unable to configure formatter 'default'
```

**Причина:** в `Porayonka_User_Web.spec` стоит `console=False`. PyInstaller в onefile-режиме с `console=False` устанавливает `sys.stdout = None` и `sys.stderr = None`. Uvicorn (внутренний web-сервер Flet) при старте вызывает `sys.stdout.isatty()` для настройки `DefaultFormatter` и падает.

**Решение:** в `porayonka-app/main_web.py` (или в общем входе `main.py` перед `ft.app` в ветке `--web`) добавить защиту: если `sys.stdout`/`sys.stderr` равны `None`, заменить их на `io.TextIOWrapper` поверх `os.devnull` (или `open(os.devnull, "w")`) **до** инициализации uvicorn. Проверить, что после этого web-сервер поднимается и браузер открывается.

**Нельзя:** менять `console=True` в `Porayonka_User_Web.spec` — тогда у пользователя Win7 будет висеть чёрное консольное окно, а это противоречит требованию «максимально просто».

### 2. Трей + уведомления для web-версии Win7

**Требование:** даже если пользователь закрыл браузер, приложение должно оставаться в системном трее, приходить «злые» уведомления о сроках, при клике на уведомление/трей — открываться вкладка браузера с контролями.

**Сейчас:** web-версия (`PORAYONKA_WEB=1`) в `main.py` явно пропускает `start_tray()` через гард `PORAYONKA_WEB`.

**Решение:**
- Убрать гард `PORAYONKA_WEB` из `ui/tray_icon.py` / `main.py` для запуска трея (оставить гард только для автозапуска, если он конфликтует с web).
- В web-режиме приложение запускает **только** локальный сервер Flet (`view=ft.AppView.WEB_BROWSER`). Pystray/trey должен работать в отдельном потоке (как и сейчас для нативной версии).
- При клике на иконку трея — открывать браузер через `webbrowser.open(f"http://{host}:{port}")`.
- При клике на balloon-уведомление — тоже открывать браузер.
- Закрытие окна/страницы **не должно** завершать процесс: в web-режиме `page.window.prevent_close` не применим, но процесс Python должен продолжать polling уведомлений и трей. Убедиться, что даже если Flet закрывает web-страницу, Python-процесс не завершается (он держит трей и фоновый поток).
- В `ui/controls/controls_tab.py` фоновый `_background_loop` (polling + уведомления) уже работает в отдельном потоке. Убедиться, что в web-режиме он продолжает работать, пока жив трей/процесс.

**Звук:** уведомления должны сопровождаться звуком `assets/pig.wav` / `assets/pig.mp3` через `ui/sound_alert.py` (уже реализовано).

### 3. User-версия: диалог «Кто вы?» должен появляться ДО таблицы

**Сейчас:** в `ui/controls/controls_tab.py`:

```python
_apply_table_geometry()
_refresh_counters()
_maybe_ask_identity()  # ← поздно
```

Пользователь видит полный список контролей (включая чужие), а потом поверх него появляется диалог выбора ФИО.

**Решение:**
- Если `edition_user` (user-редакция) и `settings["network_user"]` пустой — показать диалог **перед** первой отрисовкой таблицы. Можно отобразить заглушку («Выберите ФИО…») или пустую таблицу, пока ФИО не выбрано.
- После выбора ФИО в `_ok` диалога вызвать `_apply_filter()` и `_refresh_counters()`, чтобы сразу показались только «свои» контроли.
- После сохранения ФИО в `edition.json`/`settings` приложение должно работать как user-редакция (read-only, уведомления каждые 2 часа).

### 4. Admin-версия не должна наследовать user-фильтр из настроек

**Сейчас:** если сначала запустить user-версию, она пишет в `%APPDATA%\porayonka\controls_settings.json`:

```json
{"network_role": "user", "network_user": "Потемкин С.А."}
```

Потом при запуске admin-версии она читает те же `settings`, `network_role` остаётся `user`, и таблица фильтруется только по Потёмкину.

**Причина:** `core/edition.py::apply_edition_to_settings()` для admin-редакции не сбрасывает `network_role` и `network_user`.

**Решение:** в `apply_edition_to_settings()` для admin-редакции (`ed.get("role") == "admin"`) принудительно сбросить `settings["network_role"] = "admin"` и `settings["network_user"] = ""` (если они были не такими). Вернуть `changed = True`, чтобы настройки сохранились. Это гарантирует, что admin-версия всегда работает с полным списком, независимо от предыдущих user-запусков.

### 5. Пароль на вход для admin-версии

**Требование:** админская версия должна запрашивать пароль при старте, чтобы посторонний не мог открыть программу и внести изменения в контроли.

**Решение:**
- В `edition.json` для admin-редакции добавить поле `password` (строка). Если поле пустое или отсутствует — пароль не требуется (обратная совместимость).
- При старте `main.py`, если `load_edition()["role"] == "admin"` и `password` не пустой — показать **модальное окно ввода пароля** ДО создания вкладок. Пароль сравнивается с `edition.json` (plain text или простой хеш, на выбор агента; важно: не усложнять, но и не хранить в открытом виде рядом с exe безальтернативно — можно base64 + соль, достаточно от случайного любопытства).
- Если пароль неверный — приложение закрывается.
- Установщик (другой агент) будет запрашивать пароль при установке и писать его в `edition.json`.

### 6. Кнопка «Настройка формы» должна быть видна только во вкладке «Зональные»

**Сейчас:** в `ui/header.py` кнопка «Настройка формы» добавлена в `right_block` всегда, вне зависимости от активной вкладки. Она открывает `page._open_template_settings()`, который существует только для вкладки «Зональные».

**Решение:**
- Передать текущую активную вкладку в `create_compact_header()` (или использовать `page._current_tab` / `page._switch_tab`, если уже есть).
- Сделать `btn_settings.visible = (active_tab == "zonal")` (или эквивалент).
- Альтернативно: оставить кнопку в header, но в обработчике `on_click` ничего не делать, если сейчас не «Зональные». Но лучше скрыть — пользователь просит именно «не должна быть видна».

### 7. Обновить модалку «О программе»

**Сейчас:** в `ui/header.py` текст «О программе» устарел — сделан ещё до вкладки «Контроли».

**Решение:** обновить текст модалки «О программе»:

- Вкладки: «Следственные отделы», «Зональные криминалисты», «Контроли».
- Роли: админская и пользовательская редакции, сетевая синхронизация.
- Уведомления о сроках.
- Разработчик/контекст: Следственный комитет РФ, Ростовская область.

## Технические ограничения

- Flet строго **0.23.2**. Не повышать.
- Не добавлять `expand=True` внутрь `Column(scroll=ft.ScrollMode.AUTO)` — см. `AGENTS.md` §§15.11, 22, 37.3.
- Цвета 8-digit — только `#AARRGGBB`, не `#RRGGBBAA`. Динамические — через `with_alpha(color, "22")` → `#22RRGGBB`.
- `print()` в консоль — только ASCII (без русских букв, emoji, спецсимволов), чтобы не было `UnicodeEncodeError` на Windows cp1251.
- UI-текст (`text=...`) — на русском.
- `ft.icons.*` вместо emoji.
- Все `.update()` контролов — через `_safe_update()` (или аналогичный хелпер, если внесёшь новый). Исключение — горячие `on_hover` (тут молча пропускать).
- Не ломать рабочий функционал раундов 20–25: вкладки, фильтры, карточка, Excel, сеть, архив, вложения, роли людей, тесты.
